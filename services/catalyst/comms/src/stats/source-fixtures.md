# Statistics source fixtures

`source-fixtures.json` contains deterministic outputs from the pinned Archipelago statistics handlers and protocol encoder. Its provenance records the source revision, SHA256 of loaded application sources, runtime versions and controlled content calls. The generator normalizes application CRLF to LF before checking hashes and transpiling. Both `sources` and `sourcesLf` therefore hash that normalized TypeScript; they do not identify raw checkout bytes. `source-runtime-lock.json` pins eleven application sources and 292 dependency module/manifest hashes across 21 package/version roots. Each loaded dependency is checked before execution, including transitive imports; an advertised version alone is insufficient. The corpus is a local source harness with controlled dependencies.

The Rust tests load this JSON directly. They require no sibling checkout, Node installation or network. `source_handler_fixtures_match_pulse_state_and_all_http_aliases` replays positioned heartbeat/disconnect events into Pulse, decodes topology/discovery, and compares the HTTP output bytes. `pinned_javascript_protocol_packets_roundtrip_without_wire_changes` checks JavaScript-generated packet bytes against the shared Rust protocol. The separate `archipelago/ws/legacy-fixtures.json` corpus exercises 566 Buffer-decoder inputs, including malformed and repeated fields.

The offline integrity command checks both frozen corpora, their generators and the runtime manifest, including case inventories and source identities. It accepts Git checkout CRLF conversion by explicitly normalizing CRLF to LF:

```text
python -B tooling/archipelago-fixtures.py check
```

For authenticated regeneration, supply the pinned source tree, installed dependency directories matching the manifest, and a supported Node executable. The wrapper currently authenticates the official Node24.15.0 Windows x64 executable by SHA256. It checks all declared application sources before starting Node and applies a shared pre-execution dependency guard to both generators, including decoder transitive imports:

```text
python -B tooling/archipelago-fixtures.py regenerate
  --upstream <pinned-source-root>
  --node <node-executable>
  --node-path <dependency-search-path>
  --output-dir <temporary-output-directory>
```

The example is one command split for readability. The dependency search path uses the host's `NODE_PATH` separator; place roots containing the exact protocol and protobufjs packages first. Provision artifacts authenticated against the pinned source lockfile before running the command. It performs no downloads, package installation or install scripts. It writes temporary outputs and compares normalized generated bytes with the tracked files; it never rewrites expectations. An integrity mismatch, unsupported runtime, missing input or different corpus fails. Review source/runtime identity and the complete corpus before changing frozen pins.

The existing Rust CI runner installs the offline integrity check and its selftests. Full regeneration requires explicitly provisioned oracle inputs; the ordinary CI Rust shell does not provide that environment. Equality covers the recorded handler and decoder cases. Deployed middleware, native HTTP framing, authenticated connector timing, transport pressure and admitted-client coverage require their own evidence.
