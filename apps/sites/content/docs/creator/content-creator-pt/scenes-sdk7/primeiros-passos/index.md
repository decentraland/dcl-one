# Primeiros passos

- [Início Rápido do SDK](/docs/creator/content-creator-pt/scenes-sdk7/primeiros-passos/sdk-101/): Crie sua primeira scene do Decentraland com o Creator Hub, o SDK e vibe coding assistido por IA usando o SDK Skills oficial.
- [Fluxo de Trabalho de Desenvolvimento](/docs/creator/content-creator-pt/scenes-sdk7/primeiros-passos/dev-workflow/): Fluxo de trabalho recomendado para criar uma scene do Decentraland com o Creator Hub, da ideação até os testes e a publicação.
- [Pré-visualize a sua cena](/docs/creator/content-creator-pt/scenes-sdk7/primeiros-passos/preview-scene/): O que pode ver na pré-visualização de uma cena
- [Usando a CLI](/docs/creator/content-creator-pt/scenes-sdk7/primeiros-passos/using-the-cli/): Use a CLI do Decentraland para executar e publicar scenes. O Creator Hub é a ferramenta recomendada para a maioria dos criadores; a CLI é adequada para fluxos de trabalho avançados e automatizados.
- [Essenciais de codificação](/docs/creator/content-creator-pt/scenes-sdk7/primeiros-passos/coding-scenes/): Este conjunto vai ajudar você a entender como as coisas funcionam no client e no SDK do Decentraland.
- [Vibe Coding com IA](/docs/creator/content-creator-pt/scenes-sdk7/primeiros-passos/vibe-coding/): Crie scenes do Decentraland com assistentes de IA usando o Creator Hub e o SDK Skills oficial do Decentraland (npx skills add decentraland/sdk-skills).
- [Recursos Úteis](/docs/creator/content-creator-pt/scenes-sdk7/primeiros-passos/useful-resources/): Ferramentas, add-ons, bibliotecas de assets e projetos de exemplo que aceleram seu fluxo de trabalho de criação no Decentraland.
