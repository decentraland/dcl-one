# Scenes de Exemplo

As seguintes scenes são totalmente de código aberto e foram concebidas para funcionar bem em dispositivos móveis. Use-as como referência para a estrutura, o tratamento de input e os padrões de performance.

Jogo de tiro multiplayer com zumbis.

* **World:** `/deadsurge.dcl.eth`
* **Fonte:** [github.com/dcl-regenesislabs/dead-surge](https://github.com/dcl-regenesislabs/dead-surge)

## Cozy Farm

Simulador de agricultura.

* **World:** `/cozyfarm.dcl.eth`
* **Fonte:** [github.com/dcl-regenesislabs/cozy-farm](https://github.com/dcl-regenesislabs/cozy-farm)

## Kick Off

* **World:** `/kickoff.dcl.eth`
* **Fonte:** [github.com/dcl-regenesislabs/kickoff-2026](https://github.com/dcl-regenesislabs/kickoff-2026)

## Raft Game

* **World:** `/raft.dcl.eth`
