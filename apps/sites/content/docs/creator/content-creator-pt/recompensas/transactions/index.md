# Transações

A aba "transactions" no serviço Rewards permite que os criadores monitorem o estado das transações que estão sendo processadas pelo serviço Rewards, mostrando o estado de cada transação, seu hash, o momento em que foi criada e o valor de *Gwei* gasto.

![](/docs/_remote/1457ac052ac9d9022ca034ca.webp)

Para cada transação, você pode clicar no **botão Ver reivindicações** para ver a lista de wearables/emotes mintados nessa transação e qual usuário os recebeu.

![](/docs/_remote/cbbd9081380b1eff06dbb39e.webp)
