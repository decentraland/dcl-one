## O que é o Wearables Editor?

O Wearables Editor é uma ferramenta dentro do Builder da Decentraland que permite fazer upload, adicionar metadata e publicar os teus próprios wearables personalizados.

> Lembra-te: estes docs não explicam como criar os modelos, meshes e textures que compõem os wearables; apenas explicam como usar o Wearables Editor para fazer upload e publicar os teus wearables. Para uma introdução ao processo real de criação de wearables, começa aqui.

### **A iniciar sessão**

Para começar a fazer upload e publicar os teus wearables, vai para [**Decentraland Create**](https://decentraland.org/create).

Clique em **Iniciar sessão**, e depois **Conectar** para iniciares sessão com a tua carteira Metamask ou Fortmatic. Depois de iniciares sessão, clica em **Coleções** tab.

## Criar uma coleção

Antes de poderes fazer upload de um wearable ou de um emote, tens de criar primeiro uma coleção. Para isso, vai a [**Decentraland Create**](https://decentraland.org/create) e clica no ***Coleções*** separador. Se ainda não tens nenhuma coleção, clica no ***Nova coleção*** botão para criares uma nova.

![](/docs/_remote/64f05d583b001a1dc5539128.webp) ![](/docs/_remote/e6e4a96a1938033d36033f9e.webp)

Depois de clicares no botão, ser-te-á pedido para renomeares a tua coleção, como mostrado abaixo. Caso mudes de ideias, podes editar o nome da tua coleção a qualquer momento **antes de publicar**.

![](/docs/_remote/c9f95e65a853d6a8ec8d25ad.webp)

Agora, já estás pronto para adicionar itens a ela. Para isso, basta clicar no botão Adicionar item e arrastar e largar o ficheiro com o teu wearable/emote ou procurar no teu computador.

![](/docs/_remote/fc50d25f7580cdac09ae4a49.webp)

Depois de clicar em ***Adicionar item***, vais obter uma janela como a mostrada abaixo. Basta arrastar e largar o ficheiro com o teu wearable/emote ou procurar no teu computador.

![](/docs/_remote/3db6fae4f154b1b73fd50dc4.webp)

Se já tens uma coleção e queres adicionar mais itens a ela, basta clicar em Adicionar item e fazer upload do teu ficheiro. Podes adicionar quantos ficheiros quiseres antes de publicar a coleção.

![](/docs/_remote/5857f67a59bae2774cf081c8.webp)

*Lembra-te: não podes adicionar, remover nem alterar a raridade dos itens depois de a coleção ser publicada.*

Cada item da coleção tem:

* **Nome do item:** este nome será apresentado quando distribuíres o teu wearable ou emote no marketplace.
* **Descrição:** *(opcional)* uma breve descrição do teu item; isto é apresentado quando distribuíres o teu wearable ou emote no marketplace.
* **Categoria:** - a categoria a que o teu wearable pertence (upper-body, eyewear, skin, etc)
* **Raridade:** - a raridade determina o número máximo de NFTs que poderás fazer mint do teu wearable ou emote após a publicação. Esta é a única propriedade que não pode ser modificada depois de publicar uma coleção.
* **Tags:** *(opcional)* palavras descritivas que os utilizadores podem usar ao procurar ou filtrar itens. São relevantes para competições ou eventos!

### **Raridade**

A raridade do teu item determina o número total de NFTs que podem ser minted. A raridade é a mesma para emotes e wearables e poderás defini-la assim que fizeres upload do teu ficheiro.

| Raridade    | Número de itens |
| ----------- | --------------- |
| Único       | 1               |
| Mítico      | 10              |
| Exótico     | 50              |
| Lendário    | 100             |
| Épico       | 1,000           |
| Raro        | 5,000           |
| Pouco comum | 10,000          |
| Comum       | 100,000         |

#### Atenção!


> [!WARNING]
> ⚠️ **O nome da tua coleção, bem como o número de itens e a respetiva raridade, não pode ser alterado depois de ser publicada!**
