# 씬 관리

해당 **Scenes** 탭에는 사용 가능한 각 씬이 카드로 표시됩니다. 카드를 열어 해당 씬을 편집할 수 있으며, 거기에서 미리보기하거나 게시할 수도 있습니다.

![Creator Hub의 씬 탭으로, 맨 앞에 새 씬 카드가 있는 씬 카드 그리드가 보이며, 그리드 위에는 씬 가져오기 및 템플릿 버튼이 있고 오른쪽에는 튜토리얼 열이 있습니다.](/docs/_remote/8a4ec6d91bfb06d4402cf305.webp)

## 씬 만들기

옆의 화살표를 클릭하여 **만들기** 버튼을 선택하고 **새 씬** 새 씬을 만들려면 **새 씬** 카드를 클릭할 수도 있습니다.

![만들기 버튼의 드롭다운이 열린 상태로, 새 씬과 씬 가져오기 옵션이 보입니다.](/docs/_remote/727cb68c3c3feea0e6221431.webp)

씬 이름을 지정하고 저장 위치를 선택하라는 안내를 받게 됩니다. 기본 위치는 앱 환경 설정에서 설정한 Scenes 폴더이며, 자세한 내용은 [씬 폴더 변경](#change-the-scenes-folder).

![프로젝트 이름 필드, 폴더 선택기가 있는 프로젝트 경로 필드, 취소 및 만들기 버튼이 있는 프로젝트 생성 대화 상자.](/docs/_remote/b21de226270dbf1e41f5f2ca.webp)

이 단계를 확인하면 씬 프로젝트가 생성됩니다. 필요한 종속성을 다운로드하고 로컬 컴퓨터에 필요한 모든 항목이 들어 있는 폴더를 설정하므로 1\~2분 정도 걸릴 수 있습니다. 완료되면 씬이 다음 위치에서 열립니다. [씬 편집기](/docs/creator/content-creator-ko/scene-editor/get-started/scene-editor-essentials/).

### 템플릿으로 시작하기

빈 씬 대신 준비된 씬으로 시작하려면 **템플릿** 탭의 **Scenes** 탭에서, 또는 **템플릿** 의 행으로 **홈** 탭입니다. 템플릿은 **빈 씬** 미술관이나 나이트클럽 같은 완전한 씬까지 다양합니다. 난이도로 필터링할 수 있습니다.

![템플릿 선택 화면으로, 쉬움, 보통, 어려움 난이도 필터와 빈 씬, 미술관 템플릿, 아늑한 집 템플릿을 포함한 템플릿 카드 그리드가 보입니다.](/docs/_remote/9f7cb7f9f5985517a1f16c0d.webp)

### 씬 카드 옵션

씬 카드의 점 세 개 아이콘을 클릭하여 더 많은 옵션을 확인하세요.

![점 세 개 메뉴가 열린 씬 카드로, 복제, 폴더 위치 열기, 폴더 이름 바꾸기, 배포 보기, 내 씬에서 삭제 항목이 나열되어 있습니다.](/docs/_remote/def8b7efaebef1e28761a7ce.webp)

클릭 **복제** 기존 씬의 복사본을 만들기 위해.

씬의 표시 이름을 바꾸려면 씬을 열고 연필 아이콘을 클릭하여 **이름** 필드 및 기타 속성을 변경하세요.

디스크에서 씬의 폴더 이름을 바꾸려면 씬 카드의 점 세 개 아이콘을 클릭하고 **폴더 이름 바꾸기**. 새 폴더 이름을 입력하고 확인하세요. 폴더 이름은 운영 체제에서 유효해야 하며 같은 위치에 이미 있는 폴더와 충돌해서는 안 됩니다.

## 씬 가져오기

씬 관리자는 컴퓨터의 기본 경로에서 찾은 씬을 표시합니다.

로컬 디스크의 다른 위치에 있는 씬을 추가하려면 **씬 가져오기** 를 클릭하고 프로젝트 폴더 경로를 찾으세요. 가져온 씬은 이제 씬 관리자 화면에서 새 카드로 사용할 수 있습니다.

가져온 씬은 로컬 디스크에서 이동되지 않습니다.


> [!WARNING]
> **📔 참고**: 파일 관리자에서 가져온 씬의 폴더 이름을 직접 수동으로 바꾸거나 이동하지 마세요. 씬 편집기는 더 이상 새 경로에서 가져온 씬을 찾을 수 없습니다.


이전 웹 편집기에서 만든 씬은 클라우드에 저장됩니다. 데스크톱 씬 편집기에서 이 씬을 작업하려면 웹 편집기에서 씬을 내보내고, 압축을 풀어 폴더에 넣은 다음 데스크톱 씬 편집기에서 가져와야 합니다. 자세한 내용은 [Web Editor에서 마이그레이션하기](/docs/creator/content-creator-ko/scene-editor/get-started/migrate-from-web/) 을(를) 참조하세요.

## 씬 삭제

씬 선택 화면에서 *점 세 개* 아이콘을 누르고 *내 씬에서 삭제*.

를 선택하세요. 그러면 씬 편집기 홈 화면에서 해당 씬이 제거됩니다. 기본적으로는 컴퓨터의 파일을 삭제하지 않지만, 확인 대화 상자에는 **씬 파일도 컴퓨터에서 함께 삭제**.

![삭제 확인 대화 상자로, My Scenes에서 씬을 삭제할지 묻고 있으며, 씬의 파일도 컴퓨터에서 함께 삭제하는 옵션은 체크되지 않은 상태입니다.](/docs/_remote/710213c338c5781ee7ca3f8f.webp)

## 씬 폴더 변경

기본적으로 씬 편집기를 통해 생성된 프로젝트는 Creator Hub의 애플리케이션 데이터 디렉터리 안의 `Scenes` 폴더에 보관됩니다. 이 위치를 변경하려면:

1. 왼쪽 상단 모서리의 Creator Hub 로고를 클릭해 메인 메뉴를 열고, 그런 다음 **설정**.
2. in the **씬** 탭을 클릭하고 **씬 폴더** 를 선택하세요.

![SCENES 탭의 앱 환경 설정 대화 상자로, 폴더 선택기가 있는 Scenes Folder 경로와 Scene Dependencies 옵션인 내 모든 씬 자동 업데이트, 새 버전 업데이트 알림 받기, 아무 작업 안 함이 표시됩니다.](/docs/_remote/f3a6d0025165ce6a10282622.webp)

같은 탭에서는 씬 종속성의 새 버전이 उपलब्ध할 때 어떤 일이 일어날지도 제어합니다: 모든 씬을 자동으로 업데이트하거나, 알림을 받거나, 아무 작업도 하지 않습니다.

프로젝트의 폴더로 이동하려면 카드의 점 세 개 아이콘을 클릭하고 **폴더 위치 열기**.

## 월드 관리

Decentraland NAME 또는 ENS 도메인을 보유하고 있다면, 씬을 다음에 게시할 수 있습니다 [Decentraland 월드](/docs/creator/content-creator-ko/sdk7/publishing/publishing-options/#decentraland-worlds). 월드는 일반 씬과 마찬가지로 씬 편집기에 표시되며, 동일한 **게시** 버튼을 사용해 게시할 수 있습니다.

월드에는 게시된 각 씬의 메타데이터와는 별개인 자체 메타데이터(이름, 설명, 썸네일)가 있습니다. 단일 씬이 있는 월드에서는 이 정보가 씬의 메타데이터와 자동으로 동기화되지만, 여러 씬이 있는 월드에서는 **관리** 탭에서만 편집할 수 있습니다. 자세한 내용은 [월드 메타데이터 vs 씬 메타데이터](/docs/creator/content-creator-ko/scene-editor/publish/publish-scene/#world-metadata-vs-scene-metadata).

### 저장 공간 시각화

월드에 게시된 씬은 지갑이 소유한 모든 월드에서 공유되는 저장 한도에 포함됩니다. 이 한도는 보유 자산을 기준으로 계산됩니다. 보유한 각 Decentraland NAME 또는 LAND 구획마다 100MB가 부여되며, 지갑에 보유한 MANA 2,000개마다 추가로 100MB가 부여됩니다.

사용 중인 저장 한도와 남은 저장 한도는 두 곳에서 확인할 수 있습니다:

* 해당 **관리** Creator Hub의 섹션에서는 총 한도 중 얼마나 사용했는지와 총 저장 용량이 표시됩니다. 클릭 **세부 정보 보기** 를 통해 MANA, LAND, NAME 보유량이 어떻게 합산되는지 확인할 수 있습니다.

<img src="/docs/_remote/6b3fe18d494c053a67e9cb4f.webp" alt="" width="300">

* 해당 **월드** 탭의 [빌더](https://decentraland.org/builder/worlds).

### 씬 배포 해제

저장 공간을 확보해야 하는 경우 월드 콘텐츠 서버에서 씬의 배포를 해제할 수 있습니다. 이는 Builder 인터페이스를 통해 수행할 수 있으며, 저장 공간을 확보하기 위해 씬을 쉽게 배포 해제할 수 있게 해줍니다.

Decentraland NAME 보유자의 경우, 할당된 저장 공간을 초과하면(예: 자산 판매 또는 다른 지갑으로 이전한 경우) 상황을 해결할 수 있는 48시간의 유예 기간이 제공됩니다. 이 기간 내에 조치하지 않으면 유예 기간이 끝난 후 월드에 접근할 수 없게 됩니다.

차단된 월드에 대한 접근 권한을 복구하려면 다음 중 하나를 수행할 수 있습니다:

* 더 많은 MANA, Decentraland NAME, 또는 LAND를 확보하여 저장 용량을 늘리기
* 기존 씬의 배포를 월드 콘텐츠 서버에서 해제하여 저장 공간 확보하기

참고 [월드 크기 제한](/docs/creator/content-creator-ko/sdk7/kinds-of-projects/kinds-of-project/#size-limits) 저장 용량이 어떻게 계산되는지에 대한 자세한 정보
