> 스프링 본으로 웨어러블에 동적 물리 효과를 추가합니다

# 스프링 본

### 스프링 본이란 무엇인가요?

스프링 본(지글 본 또는 물리 본이라고도 함)은 애니메이션 클립에 의해 구동되는 것이 아니라 아바타의 움직임과 중력에 반응하여 동적으로 움직이는, 착용형 아이템에 추가된 보조 본입니다. 아바타가 걷고, 달리고, 회전할 때 머리카락, 귀걸이, 망토, 벨트, 포니테일, 기타 늘어진 액세서리가 자연스럽게 흔들리고 튀고 가라앉도록 만들어 생동감을 더해 줍니다.

스프링 본은 **아니며** 기본 아바타 아마추어의 일부입니다. Blender(또는 다른 3D 소프트웨어)에서 아바타의 기본 스켈레톤에 추가하는 보조 본이며, 업로드 후 Builder에서 물리 동작이 설정됩니다.

이 구현은 [VRM 스프링 본 표준](https://vrm.dev/en/vrm1/springbone/), 즉 VRM 및 MMD 같은 형식에서 아바타 물리에 널리 채택된 규약을 따릅니다.

![](/docs/_remote/34cee41d461f2df0b8a03bc9.webp)

### 스프링 본의 작동 방식

하나는 **스프링 체인** 은 함께 물리를 시뮬레이션하는 본의 연속이며, 최소 두 개의 본이 필요합니다: 실제 스프링 본과 끝 본입니다. 단일 스프링 본만으로는 아무 움직임도 만들 수 없습니다. 시뮬레이션에는 물리를 구동하는 스프링 본의 헤드가 필요하고, 끝 본의 헤드는 기하학적 끝점을 정의합니다. 더 긴 체인(3개 이상의 본)은 더 부드럽고 자연스러운 움직임을 보이며, 긴 머리카락이나 망토에 이상적입니다.

1. **스프링 본 부모** — 체인의 첫 번째 본입니다. 물리 설정(강성, 중력, 드래그 등)을 담당합니다. 본 이름에 `springbone` 가 포함되어 있으면 식별됩니다(대소문자 구분 없음).
2. **자식 스프링 본** — 계층 구조에서 이전 본의 자식입니다. 부모의 물리 매개변수를 상속하고 체인을 형성합니다.
3. **스프링 본 끝** — 체인의 마지막 본입니다. 체인의 기하학적 끝점을 정의하지만 시뮬레이션의 영향을 받지 않으며 어떤 메시도 변형시키지 않습니다.

스프링 본의 체인, 즉 계층 구조는 **선형적이어야 합니다**, 즉 각 본은 하나의 자식만 가질 수 있다는 뜻입니다. 자식이 두 개 이상인 본은 예상치 못한 동작을 보일 수 있습니다.

![보기 좋은 선형 스프링 체인.](/docs/_remote/69a822cfcb94b03d0ba7ebc5.webp)

![자식이 2개 이상인 본은 예상치 못한 동작을 보입니다.](/docs/_remote/9ef1ec407222b18595a504e1.webp)

### 계층 구조

스프링 본이 제대로 작동하려면 아바타의 원래 본 중 하나에 부모 연결되어 있어야 합니다. 예를 들어 머리카락과 귀걸이의 경우, 계층의 최상단 본은 ***Avatar\_Head***. 스카프의 경우 체인을 ***Avatar\_Neck*** 에 부모 연결하는 것이 좋습니다. 치마의 경우에는 ***Avatar\_Hips*** 또는 ***Avatar\_LeftUpLeg/Avatar\_RightUpLeg*** 이 유용할 수 있습니다.

이 계층 구조가 어떻게 작동하는지 주의해서 봐야 합니다.

* *Hair\_springBone\_1* (스프링 본 부모): 체인 맨 위의 본으로, 물리 설정을 가집니다
* *Hair\_springBone\_2* (자식 스프링 본): 계층 구조에서 이전 본의 자식이며 설정을 상속합니다.
* *Hair\_springBone\_end* (스프링 본 끝): 체인의 마지막 본이며 끝점 역할만 합니다.

### 명명 규칙

모든 스프링 본은 **반드시** 문자열 `springbone` (대소문자 구분 없음)을 이름에 포함해야 합니다. 해당 문자열은 어느 위치에나 올 수 있습니다:

* *SpringBone\_hair\_left*
* *hair\_springbone\_l*
* *springbone\_earring.R*

작업 흐름을 정리하기 위해 다음 형식을 사용하는 것이 좋습니다: **BodyPart/WearableName\_springBone**

예시: *Hair\_springBone\_1*, *Earring\_springBone.L* 등… Blender(또는 사용하는 다른 소프트웨어)의 좌우 명명 규칙만 따르고 있다면, 가장 잘 맞는 형식을 자유롭게 사용해도 됩니다.


> [!WARNING]
> 주의!
> 
> 스프링 본은 `springbone` 본 이름에 이 문자열이 없으면 작동하지 않습니다. 끝 본에도 반드시 사용해야 합니다.


### 제한

각 착용형 아이템은 다음 스프링 본 제한을 지켜야 합니다:

* 최대 **6** 착용형 아이템당 스프링 체인 수
* 최대 **12** 총 스프링 본 수(모든 체인의 본 수 합계)
* 최대 체인 깊이 **6** 본

## Blender에서 스프링 본 만들기

스프링 본은 기본 아바타 아마추어를 위해 Blender에서 만드는 추가 본입니다. 물리 매개변수는 나중에 Builder에서 설정되며, 지금은 본 계층만 설정하면 됩니다.

새 본을 만들려면 아바타 아마추어를 선택하고, **편집 모드에서**, 커서를 본을 만들 위치에 두고 다음을 누르세요 **Shift+A**. 다른 방법은 기존 본을 복제하는 것으로, 다음을 눌러 할 수 있습니다 **Shift+D**. 첫 번째 본을 만든 후 **E** 를 눌러 돌출시켜 체인의 나머지를 만듭니다.

![커서 위치에 본을 만들려면 Shift+A를 누르세요.](/docs/_remote/ba60206570eff70b8cf1e047.webp)

스프링 체인은 스켈레톤 부모에 연결되어 있을 필요가 없으므로 메시의 아무 곳에나 배치할 수 있다는 점이 중요합니다. 하지만 스프링 체인 자체는 **연결되어야 합니다** , 스프링 본을 오프셋할 수는 없습니다.

본을 만든 후에는 앞서 언급한 명명 규칙에 따라 이름을 바꾸고, 체인을 올바른 본에 부모 연결해야 합니다. 점선은 체인의 부모를 보여 줍니다. 아무것도 없으면 체인에 부모가 없다는 뜻입니다. 에서 **편집 모드에서**, 자식을 먼저 선택한 다음 부모를 선택하고 다음을 누릅니다 **Ctrl+P** > **오프셋 유지**.

![자식을 먼저 선택한 다음 부모를 선택하고 Ctrl+P를 눌러 본을 부모 연결합니다.](/docs/_remote/c74a20db130a6672bd12b248.webp)

본 이름을 바꾸려면 편집 모드 또는 포즈 모드에서 선택한 다음 본 속성 탭으로 가서 명명 규칙에 맞게 이름을 바꾸세요. 체인의 모든 본에 대해 이 작업을 수행하세요.

![](/docs/_remote/ce5dc94e935f8d3e30031022.webp)


> [!NOTE]
> 팁!
> 
> 본이 올바르게 배치되었는지 확인하려면 **오브젝트 모드** 에서 **편집 모드에서**본을 배치하려는 영역의 버텍스를 선택하고(루프나 버텍스 그룹일 수 있음) > **Shift+S** > **선택한 항목으로 커서**
> 
> 다시 **오브젝트 모드**, 아마추어를 선택하고 > **편집 모드에서** > 원하는 본을 선택하고 > **Shift+S** > **커서를 선택한 항목으로**.


![Shift+S를 사용해 본을 메시의 올바른 위치에 배치하세요.](/docs/_remote/f67fcda5bdba4aa2338aeafe.webp)

### 메시 스키닝

스키닝은 메시를 아마추어에 바인딩하여 함께 움직이게 하는 과정입니다. 이를 위해 각 본이 버텍스에 얼마나 영향을 줄지(가중치)를 정의합니다. 가중치가 클수록 본이 메시를 더 많이 변형합니다. 이를 위해 **오브젝트 모드**, 먼저 메시를 선택하고 다음을 누른 뒤 **Shift** 를 누르고 아마추어를 선택한 다음 **Ctrl+P**. 이 작업에는 두 가지 방법이 있습니다.  **빈 그룹으로** 또는 **자동 가중치로**.

![](/docs/_remote/af0366e9dd4fcda637585505.webp)

#### 자동 가중치로

이름 그대로, 이 방법에서는 Blender가 아마추어의 각 본에 대한 버텍스 그룹을 만들어 각 그룹에 자동 가중치를 부여함으로써 스킨 가중치를 자동으로 설정하려고 합니다. 어떤 경우에는 잘 작동하지만, 일부 조정이 필요할 수도 있습니다. 생성된 그룹은 **데이터** 탭에 표시됩니다.

특정 본이 메시에 영향을 줄 필요가 없다고 확실히 알고 있다면, 잠금 아이콘을 클릭해 잠그고, 드롭다운 메뉴에서 **잠금 아이콘** 를 선택해 오브젝트에서 제거하면 됩니다. 예를 들어 머리카락 작업 중이라면 발과 손에 대한 그룹은 의미가 없습니다. 이런 경우 아래 예시처럼 머리나 스프링 본이 아닌 것은 모두 삭제하세요. 또한 스프링 체인의 끝 본 **잠금 해제된 모든 그룹 삭제** 그룹도 반드시 삭제하세요.

![버텍스 그룹 삭제.](/docs/_remote/7241732fd5c95ea8e45c2fc5.webp)

#### 빈 그룹으로

이 방법에서는 Blender가 아마추어의 각 본에 대한 모든 버텍스 그룹을 만들지만 기본 가중치는 0입니다. 가중치는 편집 모드에서 수동으로 지정하거나 Weight Paint 모드에서 칠해야 합니다. 이 방식은 어떤 그룹이 무엇에 영향을 주는지 더 세밀하게 제어할 수 있으며, 하드 서피스나 특정 그룹에 완전히 할당되어야 하는 오브젝트에 특히 유용합니다. 어쨌든 가중치를 지정한 후에는 포즈 모드에서 테스트하고 Weight Paint에서 다시 조정해야 합니다.

![빈 그룹으로 부모 연결.](/docs/_remote/7117bb961a31e9863ce1f2b6.webp)

#### 가중치 칠하기

스키닝된 메시를 테스트하려면 아마추어를 선택하고 **포즈 모드**, 키 프레임을 설정한 다음 본을 회전시켜 다른 포즈를 만들고 또 다른 키프레임을 설정하세요. 이렇게 하면 움직임에 따라 메시가 어떻게 변형되는지 확인할 수 있습니다. 포즈 설정이 끝나면 다시 **오브젝트 모드**, 메시를 선택하고 **가중치 페인트**.

![](/docs/_remote/b65b3d58d5501afc7e9c1613.webp)

에서 **가중치 페인트**, 도구 탭에서 스킨 가중치를 조정할 수 있는 다양한 브러시를 찾을 수 있습니다. 편집하려는 버텍스 그룹을 선택하고(잠겨 있다면 잠금을 해제해 영향도를 편집할 수 있게 하세요) 브러시로 영향을 추가하거나 제거하세요. 검정은 영향 0을 의미하고, 빨강은 해당 그룹이 메시를 완전히 영향한다는 뜻입니다. 다음에서 와이어프레임을 활성화하면 **오버레이** 무엇을 칠하고 있는지 더 쉽게 볼 수 있습니다.

![](/docs/_remote/90b7445921156a708238f07c.webp)

추가, 빼기 또는 스무스 브러시를 사용해 원하는 결과를 얻으세요. 메시가 어떻게 변형되는지, 가중치가 없는 버텍스가 남아 있지 않은지도 확인하려면 다양한 극단적인 포즈도 시험해 보세요. 결과가 만족스럽다면 이제 내보낼 차례입니다!

### 내보내기

내보내기 전에 포즈 테스트 중 생성된 애니메이션 클립을 모두 삭제하세요. 포즈 모드로 가서 다음을 눌러 모든 본을 선택하고 **하나는** 그리고 다음을 누르세요 **Ctrl+R**, 그런 다음 **Ctrl+S** 그리고 마지막으로 **Ctrl+G** 아마추어의 모든 변형을 삭제합니다. 그런 다음 오브젝트 모드로 돌아가 표시 모드를 View Layer에서 Blender File로 바꾸고, Actions를 펼친 뒤 마우스 오른쪽 버튼으로 클릭해 애니메이션 파일을 삭제하세요.

![](/docs/_remote/d7f2ca8abd2e46afcdc74627.webp)

씬에 다른 오브젝트(예: 아바타 메시)가 있다면 Outliner의 눈 아이콘을 클릭해 표시를 끄세요. 그런 다음 **파일** > **내보내기** > **gltf 2.0 (.glb, .gltf)**. 내보내기 설정에서 Include를 펼치고 **다음으로 제한** 토글 **보이는 오브젝트**. Export를 클릭하면 파일을 Builder에 업로드할 준비가 끝납니다!

![](/docs/_remote/22840326793df160d616c22f.webp)

## Builder에서 스프링 본 구성하기

다음을 포함한 착용형 아이템을 업로드하면 `springbone`-이름의 본을 Builder가 자동으로 감지해 **스프링 본** 구성 패널을 표시합니다.

![](/docs/_remote/6198c56189e1f79689bb9bd2.webp)

이 패널에서 각 스프링 루트 본의 물리 매개변수를 설정할 수 있습니다. Builder의 아바타 미리보기는 변경 사항을 즉시 반영하므로 실시간으로 동작을 미세 조정할 수 있습니다.


> [!NOTE]
> Builder에서는 새 스프링 본을 추가할 수 없습니다. 본은 업로드된 `.glb` 파일에 올바른 명명 규칙으로 이미 존재해야 합니다. Builder는 감지된 스프링 본의 물리 매개변수만 설정할 수 있습니다.


### 매개변수 참고

#### 강성력

|         |       |
| ------- | ----- |
| **범위**  | 0에서 4 |
| **기본값** | `2.0` |

본이 제자리 자세로 돌아가려는 힘을 얼마나 강하게 제어하는지 조절합니다. 이것은 복원력입니다. 스프링의 "단단함"이라고 생각하면 됩니다.

* **0**: 본이 제자리로 전혀 돌아가지 않으며, 중력에 따라 축 늘어진 채로 매달립니다.
* **낮은 값** (예: 0–1): 본이 느슨하고 처져 있으며 자유롭게 흔들립니다. 길게 흩날리는 머리카락이나 가벼운 늘어진 액세서리에 좋습니다.
* **높은 값** (예: 3–4): 본이 단단해서 원래 위치에 가깝게 유지되고 빠르게 되돌아갑니다. 짧은 머리카락이나 단단한 액세서리에 좋습니다.

#### 중력 세기

|         |       |
| ------- | ----- |
| **범위**  | 0에서 2 |
| **기본값** | `0`   |

매 프레임마다 본을 끌어당기는 중력의 크기를 제어합니다.

* **0**: 중력 효과가 없습니다. 본은 움직임 관성과 강성의 영향만 받습니다.
* **낮은 값** (예: 0.3–0.8): 미묘한 중력 당김으로, 대부분의 액세서리에 적합합니다.
* **높은 값** (예: 1.5–2.0): 강한 중력 당김으로 본이 크게 처집니다.

#### 중력 방향

|         |                           |
| ------- | ------------------------- |
| **형식**  | X, Y, Z 벡터                |
| **기본값** | `X: 0, Y: -1, Z: 0` (아래쪽) |

월드 공간에서 중력의 방향을 설정합니다. 기본적으로 중력은 아래쪽(Y = -1)으로 당겨 자연스러운 중력을 시뮬레이션합니다.

| X  | Y  | Z  | 효과              |
| -- | -- | -- | --------------- |
| 0  | -1 | 0  | 아래쪽(자연 중력, 기본값) |
| 0  | 1  | 0  | 위쪽(부유/초자연적 효과)  |
| 1  | 0  | 0  | 왼쪽              |
| -1 | 0  | 0  | 오른쪽             |
| 0  | 0  | 1  | 앞쪽              |
| 0  | 0  | -1 | 뒤쪽              |

축을 조합할 수 있습니다(예: `X: 0.5, Y: -0.5, Z: 0`) 대각선 방향을 만들 수 있습니다. 이는 바람 같은 효과를 시뮬레이션하거나 초자연적 캐릭터에 떠 있는 듯한 느낌을 주는 데 유용합니다.

#### 드래그 힘

|         |       |
| ------- | ----- |
| **범위**  | 0 – 1 |
| **기본값** | `0.5` |

본이 운동량을 얼마나 빨리 잃고 가라앉는지 제어합니다. 공기 저항이나 감쇠라고 생각하면 됩니다.

* **낮은 값** (예: 0–0.2): 마찰이 거의 없는 진자처럼, 본이 안정되기 전 오랫동안 자유롭게 흔들립니다.
* **높은 값** (예: 0.7–1.0): 본이 움직인 뒤 거의 즉시 안정되어 무겁거나 감쇠된 느낌을 줍니다.
* **1**: 본이 거의 움직이지 않습니다. 최대 감속입니다.

#### 중심(선택 사항)

|         |            |
| ------- | ---------- |
| **형식**  | 본 이름(드롭다운) |
| **기본값** | 없음         |

아바타의 한 지점을 기준으로 스프링 본의 움직임을 계산하기 위한 선택적 기준 본입니다. 월드 공간을 기준으로 하지 않으므로 아바타가 움직일 때(걷기, 달리기) 스프링 체인이 과도하게 흔들리는 것을 방지합니다.

**중심 본이 없으면**, 스프링은 월드 공간에서 관성을 계산합니다. 아바타가 한 걸음 내디딜 때마다 마치 온 세상이 움직인 것처럼 본이 반응해 이동 시 흔들림이 과장됩니다.

**중심 본이 있으면**, 시뮬레이션은 해당 본의 공간을 기준 프레임으로 사용하므로 아바타의 *로컬* 움직임(머리 돌리기, 몸 굽히기)만 스프링 반응을 일으킵니다.

착용형 아이템이 몸의 어디에 있는지에 따라 중심 본을 선택하세요:

| 착용 위치              | 추천 중심 본        |
| ------------------ | -------------- |
| 머리(머리카락, 귀걸이, 티아라) | `Avatar_Head`  |
| 상체(망토, 목걸이)        | `Avatar_Spine` |
| 하체(벨트, 치마 액세서리)    | `Avatar_Hips`  |


> [!WARNING]
> 중심 본은 **절대** 어떤 스프링 체인에도 포함되면 안 됩니다. 기본 아바타 아마추어의 본이어야 합니다.

## 제한 사항

스프링 본을 다룰 때는 다음 제한 사항을 염두에 두세요:

* **콜라이더 없음**: 스프링 본은 아바타의 몸이나 다른 본과 충돌하지 않습니다. 극단적인 포즈에서는 체인이 몸 메시에 관통될 수 있습니다. 향후 버전에서 콜라이더 지원이 추가될 수 있습니다.
* **착용형 아이템 간 상호작용 없음**: 각 착용형 아이템의 스프링 체인은 독립적입니다. 서로 다른 착용형 아이템의 체인은 서로 영향을 주지 않습니다.
* **전역 바람 없음**: 씬 수준의 바람 힘은 없습니다. 다음을 조정하여 착용형 아이템별 바람 효과를 근사할 수 있습니다. `gravityDir` 를 대각선 방향으로 설정하면 됩니다.
* **원격 아바타에서의 성능**: 성능을 위해 로컬 플레이어에서 멀리 떨어진 아바타에서는 스프링 본 시뮬레이션이 비활성화됩니다. 가까운 아바타는 스프링 본 물리를 정상적으로 표시합니다.
* **대체 클라이언트 호환성**: 스프링 본이 있는 착용형 아이템은 대체 클라이언트와 이전 Explorer 버전과 하위 호환되지만, 스프링 본 요소는 정적으로 유지됩니다. 경우에 따라 약간의 시각적 문제가 있을 수 있습니다.

## 기술 참고

스프링 본 물리는 함께 작동하는 두 개의 별도 산출물을 사용합니다:

1. **해당 `.glb` 파일** 에는 본 이름만 포함됩니다( `springbone` 토큰)과 그 계층 구조가 포함됩니다. 모델 파일에는 물리 매개변수가 저장되지 않습니다.
2. **착용형 아이템의 메타데이터** (`wearable.data.springBones`)에는 모든 물리 매개변수가 JSON으로 들어 있습니다.

Builder에서 매개변수를 설정하면 착용형 아이템의 메타데이터에 저장되며 — `.glb` 파일은 매개변수 편집으로는 변경되지 않습니다.

이 형식을 직접 다룰 필요는 없습니다. 읽기와 쓰기는 Builder가 처리합니다. 이 섹션은 참고용입니다.

### `.glb` 노드 계층 구조(예시)

모델 파일에는 본 이름과 부모-자식 관계만 포함됩니다:

```json
{
  "asset": {"version": "2.0"},
  "nodes": [
    {"name": "Avatar_Head", "children": [1, 2]},
    {"name": "SpringBone_earring_r", "children": [3]},
    {"name": "SpringBone_hair_left", "children": [4]},
    {"name": "springbone_earring_r_tip"},
    {"name": "SpringBone_hair_left_tip"}
  ]
}
```

### 아이템 메타데이터 (`wearable.data.springBones`)

물리 매개변수는 GLB 콘텐츠 해시를 키로 하여 착용형 아이템의 메타데이터에 저장됩니다:

```json
{
  "version": 1,
  "models": {
    "bafkreialsvt77jvpy673cnugp5ggnxfaalfncufweayuk3jbxskh3pelkm": {
      "SpringBone_earring_r": {
        "stiffness": 0.5,
        "gravityPower": 1.0,
        "gravityDir": [0, -1, 0],
        "drag": 0.6,
        "isRoot": true,
        "center": "Avatar_Hips"
      },
      "SpringBone_hair_left": {
        "stiffness": 2.0,
        "gravityPower": 0.8,
        "gravityDir": [0, -1, 0],
        "drag": 0.4,
        "isRoot": true
      }
    }
  }
}
```

* `models` 는 GLB 콘텐츠 해시를 키로 사용합니다. 남성과 여성 표현이 같은 `.glb` 하나의 항목을 공유합니다.
* 각 본 항목은 `.glb` 모델의 정확한 노드 이름을 사용합니다(대소문자 구분 있음).
* 끝 본(예: `springbone_earring_r_tip`) 메타데이터 항목이 필요하지 않습니다 — 이는 기하학적 끝점으로만 사용됩니다.

### 메타데이터 매개변수

| 매개변수         | 유형   | 기본값          | 설명                                                |
| ------------ | ---- | ------------ | ------------------------------------------------- |
| `강성`         | 실수   | `2.0`        | 기본 자세로 되돌리는 복원력입니다. 범위: 0–4.                      |
| `중력 세기`      | 실수   | `0`          | 중력의 크기입니다. 범위: 0–2.                               |
| `gravityDir` | vec3 | `[0, -1, 0]` | 월드 공간에서의 중력 방향입니다.                                |
| `드래그`        | 실수   | `0.5`        | 감쇠 / 감속 계수입니다. 범위: 0–1.                           |
| `루트 여부`      | 불리언  | —            | 이 노드가 스프링 체인의 루트인지 여부입니다. 루트여야 함 `true` 루트 본에 대해. |
| `중심`         | 문자열  | —            | 선택 사항. 상대 관성 계산을 위한 참조 본의 이름.                     |
