# 하드웨어 요구 사항

다음 사양은 Android 및 iOS용 Decentraland 모바일 앱에 적용됩니다. 데스크톱 요구 사항은 다음을 참조하세요. [Decentraland 101](https://github.com/decentraland/docs/tree/main/player/faqs/decentraland-101.md).


> [!NOTE]
> 아래의 모바일 하드웨어 목표는 2026년 4월 기준으로 정확하며, 앱이 발전함에 따라 변경될 수 있습니다.


## Android

|     | 최소 요구 사항                 | 권장 사양                 |
| --- | ------------------------ | --------------------- |
| OS  | Android 12               | Android 13 이상         |
| 기기  | Samsung Galaxy A53 또는 동급 | Samsung Galaxy A54 이상 |
| RAM | 4GB                      | 6GB 이상                |

## iOS

|    | 최소 요구 사항            | 권장 사양        |
| -- | ------------------- | ------------ |
| OS | iOS 18              | iOS 18 이상    |
| 기기 | iPhone 13 / SE(3세대) | iPhone 14 이상 |

다음에서 모바일 앱을 받으세요. [App Store(iOS)](https://apps.apple.com/app/decentraland/id6478403840?utm_source=docs&utm_medium=internal&utm_content=ios) 또는 [Google Play(Android)](https://play.google.com/store/apps/details?id=org.decentraland.godotexplorer&pcampaignid=web_share&utm_source=docs&utm_medium=internal&utm_content=android).
