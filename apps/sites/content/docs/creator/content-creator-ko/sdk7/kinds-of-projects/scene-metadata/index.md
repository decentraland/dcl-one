# 씬 메타데이터

씬은 공간적으로 구획된 Decentraland 프로젝트로, 하나 또는 여러 파셀에 매핑됩니다. 씬이 Decentraland Genesis City 맵에 배포되면 플레이어는 씬의 좌표를 방문하여 체험할 수 있습니다. 씬이 a에 배포되면 [월드](/docs/creator/content-creator-ko/sdk7/publishing/publishing-options/#decentraland-worlds), 플레이어는 URL을 통해 방문할 수 있습니다.

참조 [씬의 파일](/docs/creator/content-creator-ko/sdk7/kinds-of-projects/scene-files/) 를 참조하여 씬 프로젝트에서 사용되는 파일 목록을 확인하세요.

## 메타데이터

Creator Hub의 [씬 편집기에서](/docs/creator/content-creator-ko/scene-editor/get-started/about-editor/), 씬을 열고 **연필 아이콘을 클릭하세요**.

![](/docs/_remote/a64bc0ae30e4d852f97ccd78.webp)

그러면 씬 메뉴가 열리며, 여기에서 여러 속성을 설정할 수 있습니다.

![](/docs/_remote/c3618719dd688d071c5d267b.webp)

또는 다음의 `scene.json` 파일을 직접 편집할 수도 있습니다. 모든 이러한 값은 여기에 저장됩니다.


> [!WARNING]
> **📔 참고**: 이 페이지에 언급되지 않은 사용자 지정 필드는 `scene.json` 파일에 추가하지 마세요. 씬을 불러오는 데 문제가 생길 수 있습니다.


## 씬 제목, 설명, 이미지

플레이어를 끌어들이고 무엇을 기대해야 하는지 알 수 있도록 씬에 제목, 설명, 썸네일 이미지를 지정하는 것은 매우 중요합니다.

플레이어가 맵에서 여러분의 씬 파셀을 선택하면 모달에 이 정보가 표시됩니다. 또한 다음과 같이 텔레포트될 때 확인 화면에서도 보게 됩니다. [텔레포트](/docs/creator/content-creator-ko/sdk7/interactivity/external-links/) 될 때. 여기에서 설득력 있는 데이터를 설정하면 씬으로의 트래픽 유입에 크게 도움이 됩니다.

플레이어가 월드를 탐색해 여러분의 씬에 들어오면, 미니맵 아래에서 씬 제목을 읽을 수 있습니다.

![](/docs/_remote/0e2898c7018cc52a2d72b72d.webp)

Scene Editor의 씬 메뉴를 통해 이 데이터를 추가하세요.

다른 개발자가 연락할 수 있기를 원한다면, 씬에 연락처 정보도 추가할 수 있습니다.


> [!NOTE]
> **📔 참고**: 월드는 씬의 메타데이터와는 별도로 자체 이름, 설명, 썸네일을 유지합니다. 월드에 단일 씬이 포함되어 있으면, 월드의 메타데이터는 매번 퍼블리시할 때마다 씬의 메타데이터에서 업데이트됩니다. 여러 씬이 포함되어 있으면 월드의 메타데이터는 독립적이며 Creator Hub의 **관리** 탭에서만 편집할 수 있습니다. 참조 [월드 메타데이터 vs 씬 메타데이터](/docs/creator/content-creator-ko/scene-editor/publish/publish-scene/#world-metadata-vs-scene-metadata).


### 씬 썸네일

썸네일은 `navmapThumbnail` 필드에서 설정됩니다. 이것은 *.png* 또는 *.jpg* 비율의 이미지여야 합니다. **16:9** 종횡비 *1920x1080* 픽셀 크기를 목표로 하세요. 같은 16:9 비율만 유지된다면 다른 크기도 사용할 수 있습니다.

플랫폼의 일부 영역은 썸네일의 축소된 정사각형 버전을 표시하며, 중앙 *1080x1080* 픽셀로 잘라냅니다. 텍스트나 로고처럼 중요한 요소는 잘리지 않도록 안전 영역 안에 두세요.


> [!WARNING]
> **📔 참고**: Creator Hub는 16:9가 아닌 이미지를 허용하지 않습니다. 수동으로 `navmapThumbnail` 다른 형태의 이미지로 설정하면 이를 표시하는 클라이언트에서 예기치 않게 늘어나거나 잘릴 수 있습니다. 참조 [씬 썸네일](/docs/creator/content-creator-ko/scene-editor/configure/scene-settings/#scene-thumbnail).


![씬 썸네일 안전 영역: 전체 1920x1080 이미지이며, 중앙 1080x1080 정사각형이 안전 영역으로 표시되고 좌우 띠는 잘리는 영역으로 표시됩니다.](/docs/_remote/a4fca710bad41737e2da1248.webp)

의 이미지는 `navmapThumbnail` 프로젝트 폴더의 이미지 파일 경로여야 합니다. 다른 곳에 호스팅된 이미지의 URL 링크일 수도 있습니다.


> [!WARNING]
> **📔 참고**: 이미지를 다른 곳에 호스팅하는 경우, 다른 사이트에서 콘텐츠를 표시할 수 있도록 CORS 정책이 허용적인 사이트인지 확인하세요.



> [!WARNING]
> **📔 참고**: 이 필드가 `assets/Images/autogenerated-thumbnail.png` (또는 `assets/images/autogenerated-thumbnail.png` 이전 프로젝트에서는)을 가리키지 마세요. Creator Hub는 썸네일을 생성할 때마다 정확히 이 파일을 덮어씁니다. 참조 [파일 이름을 autogenerated-thumbnail.png로 지정하지 마세요](/docs/creator/content-creator-ko/scene-editor/configure/scene-settings/#dont-name-your-file-autogenerated-thumbnailpng).


## 카테고리

플레이어가 Decentraland를 탐험하는 데 도움이 되도록 씬에 카테고리를 추가할 수 있습니다. 이는 [Decentraland Places dApp](https://places.decentraland.org) 에서 각 장소를 분류하고 플레이어가 관심 있는 것을 더 쉽게 찾을 수 있도록 하는 데 사용됩니다.

**카테고리** 다음의 미리 정의된 목록에서 선택해야 합니다:

* 🎨 아트
* 🕹️ 게임
* 🃏 카지노
* 👥 소셜
* 🎶 음악
* 👠 패션
* 🪙 크립토
* 📚 교육
* 🛍️ 쇼핑
* 🏢 비즈니스
* 🏅 스포츠
* 🏃 파쿠르

씬은 하나 이상의 카테고리에 속할 수 있으며, 최대 3개의 카테고리를 나열할 수 있습니다.

다음에서 `scene.json` 카테고리는 다음의 `태그` 배열에 나열됩니다.

다음은 미리 정의된 카테고리입니다:

* `art`
* `game`
* `casino`
* `social`
* `music`
* `fashion`
* `crypto`
* `education`
* `shop`
* `business`
* `sports`
* `parkour`

예를 들어, 씬은 다음과 같이 태그할 수 있습니다. `game` 및 `casino` 를 다음과 같이 추가하여 `scene.json`

```json
  "tags": [
    "game",
    "casino",
  ],
```

그 후 씬은 Places dApp에서 `game` 및 `casino` 카테고리 아래에 표시됩니다.

## 연령 등급

이 **연령 등급** 필드는 씬의 콘텐츠를 분류하는 데 사용됩니다. Decentraland는 18세 이상 플랫폼입니다. 다음 옵션을 사용할 수 있습니다:

* **🟡 `A` 성인용 (18+)**: 이는 Decentraland의 [이용 약관](https://decentraland.org/terms)에 명시된 최소 연령 요건입니다. 욕설이나 강한 폭력, 노골적인 콘텐츠, 도박, 또는 알코올, 담배, 마약 같은 물질이 포함된 성인용 콘텐츠가 있는 경우 이 카테고리를 선택하세요.

연령 등급을 `scene.json`를 통해 편집할 때, 등급은 **단일 문자 코드**이므로, **A** 성인용을 의미하는 `등급` 필드는 json 트리의 루트 수준에 위치합니다.

![](/docs/_remote/fcf06d87514878da9f3396fa.webp)

```json
 "rating": "A"
```

### 제한된 콘텐츠

씬에는 세 번째 카테고리가 있습니다: 🔴 `R` 제한됨을 의미합니다. 이 등급은 Decentraland의 [콘텐츠 정책](https://decentraland.org/content)을 위반한 씬에 콘텐츠 관리자에 의해 수동으로 적용됩니다. 위반에는 다음이 포함될 수 있지만 이에 국한되지는 않습니다:

* 의심스러운 콘텐츠 또는 스팸
* 학대적이거나 혐오를 조장하는 콘텐츠
* 성적인 콘텐츠 또는 품위 훼손 콘텐츠
* 아동 학대
* 괴롭힘 또는 따돌림
* 테러/폭력 조장
* IP/저작권 침해

이 등급이 적용된 씬은 로드되지 않으며 아무도 상호작용할 수 없습니다. 씬이 이 범주에 해당한다면, 다음을 준수하도록 검토하고 업데이트해야 합니다. [콘텐츠 정책](https://decentraland.org/content).

## 기능 토글

플레이어가 이를 남용하지 못하도록 특정 씬에서 비활성화할 수 있는 기능들이 있습니다. 씬 설정의 **설정** 탭에서 이를 구성하세요.

![](/docs/_remote/5c421faac03084ef8453fff3.webp)

현재는 다음 기능만 이렇게 처리됩니다:

* **음성 채팅**: 플레이어가 마이크를 사용해 주변의 다른 플레이어와 음성 채팅으로 대화하는 것을 의미합니다.
* **포터블 경험 비활성화**: 이 설정은 플레이어가 여러분의 씬 안에 서 있을 때 해당 플레이어의 모든 포터블 경험의 동작을 설정합니다. 여기에는 [포터블 경험](/docs/creator/content-creator-ko/sdk7/kinds-of-projects/portable-experiences/) 뿐만 아니라 [스마트 웨어러블](/docs/creator/content-creator-ko/sdk7/kinds-of-projects/smart-wearables/)도 포함됩니다. 이 설정을 사용하면 모두 활성화 상태로 유지(기본값), 비활성화, 또는 UI 숨김 중 하나를 선택할 수 있습니다. 이는 예를 들어 파쿠르 도전에서 제트팩을 사용하는 것처럼 포터블 경험이 일부 플레이어에게 불공정한 이점을 줄 수 있는 씬에 유용합니다. 또한 블록체인 거래가 이루어지는 씬이나, 악의적인 포터블 경험이 씬의 UI를 가장할 가능성이 있는 씬에서도 이를 방지하는 것이 좋습니다.

다음의 `scene.json` 파일에서는 이 토글들이 `featureToggles` 아래에서 관리됩니다. 해당 기능들은 *disabled* 로 지정되지 않는 한 기본적으로 활성화되어 있습니다. `scene.json` 파일에

```json
"featureToggles": {
    "voiceChat": "disabled",
    "portableExperiences": "enabled" | "disabled" | "hideUi"
},
```

만약 `featureToggles` 속성이 여러분의 `scene.json` 파일에 존재하지 않으면, JSON 트리의 루트 수준에 생성하세요.

### 팁 받기

플레이어가 여러분의 씬을 방문할 때 팁을 받을 수 있습니다. 팁 받기를 활성화하려면 **세부 정보** 탭으로 이동해 **크리에이터 지갑 주소**.

![](/docs/_remote/9c99df3549a6adf960b5d332.webp)

아래에 Ethereum 주소를 입력하세요. 또한 `scene.json` 파일의 `creator` 필드에 씬의 팁 주소를 제공할 수도 있습니다.

```json
  "creator": "0x1234567890123456789012345678901234567890"
```

플레이어가 여러분의 씬을 방문하면 화면 왼쪽 상단에 돼지저금통 아이콘이 표시됩니다. 이를 클릭하면 팁을 보낼 수 있는 모달이 열립니다. 이 메뉴는 맵에서 씬 정보를 열어도 접근할 수 있습니다.

![](/docs/_remote/2e01580f2f84c6ab2edcbf00.webp)

팁 모달에서 플레이어는 보낼 MANA의 양을 선택할 수 있습니다. 팁을 보내려면 플레이어는 지갑에 MANA를 보유하고 있어야 합니다. 제공한 주소가 Decentraland NAME과 연결되어 있으면, 이 모달에는 Ethereum 주소 옆에 지갑 소유자의 이름이 표시됩니다.

![](/docs/_remote/1cf2999882d7d551c8ac0687.webp)

플레이어가 팁을 보낼 때마다 Decentraland 알림 탭에서 알림을 받게 됩니다.

## 스폰 위치

이 **스폰 설정** 로 지정되지 않는 한 기본적으로 활성화되어 있습니다. **설정** 탭에서는 플레이어가 좌표를 브라우저에 직접 입력하거나 텔레포트하여 여러분의 씬에 직접 접근할 때 어디에서 스폰될지 정의합니다.

![](/docs/_remote/ce7ddfc8e55124a7c4396831.webp)

씬 안에서 스폰될 때 나무나 계단처럼 플레이어의 이동을 막는 오브젝트가 있을 수 있습니다. 씬에 높은 지형이 있을 수도 있습니다. 플레이어가 이동할 수 없는 위치에서 스폰되는 것을 방지하려면 특정 위치에 여러 스폰 지점을 설정할 수 있습니다.

위치는 씬 내부의 좌표로 이루어집니다. 이 숫자는 파셀 내의 위치를 의미하며, 씬 코드에서 Transform 컴포넌트를 사용해 [엔티티를 배치할 때 사용하는 것과 비슷합니다](/docs/creator/content-creator-ko/sdk7/3d/entity-positioning/).


> [!WARNING]
> **📔 참고**: 모든 스폰 지점은 씬을 구성하는 파셀 안에 있어야 합니다. 플레이어를 이 파셀들의 공간 밖에 스폰시킬 수는 없습니다.


다음의 **랜덤 오프셋** 체크박스를 선택하면 스폰 지점 주변에서 플레이어가 무작위로 오프셋되도록 할 수 있습니다. 이렇게 하면 스폰 시 모든 플레이어가 서로 겹쳐 나타나는 것을 방지할 수 있으며, 특히 사람이 많은 씬에서 보기 좋지 않은 문제를 줄여줍니다.  **최대 오프셋** 값은 원래 스폰 지점으로부터 X축과 Z축 모두에서 가능한 최대 거리입니다.

다음을 설정하세요. **카메라 타깃** 플레이어가 씬에 들어올 때 바라보는 방향을 제어합니다. 이를 통해 첫인상을 더 잘 제어하고 특정 방향으로 유도할 수 있습니다. 기본값은 `{x: 8, y:1, z:8}`이며, 단일 파셀 씬에서는 씬의 중심, 더 큰 씬에서는 왼쪽 아래 파셀의 중심입니다.

클릭하세요 **스폰 지점 추가** 를 눌러 원하는 만큼 스폰 지점을 나열하세요. 플레이어는 그중 하나에 무작위로 나타납니다.

### JSON의 스폰 지점

스폰 지점은 다음을 통해서도 구성할 수 있습니다. `scene.json` 파일의 `spawnPoints` 필드에 씬의 팁 주소를 제공할 수도 있습니다.

```json
  "spawnPoints": [
    {
      "name": "spawn1",
      "position": {
        "x": 5,
        "y": 1,
        "z": 4
      }
    }
  ],
```

하나의 씬에는 여러 스폰 지점을 둘 수 있습니다. 이는 특히 큰 씬에서 유용합니다. 여러 스폰 지점을 두려면, 단순히 배열로 나열하면 됩니다.

```json
  "spawnPoints": [
    {
      "name": "spawn1",
      "position": {
        "x": 5,
        "y": 1,
        "z": 4
      }
	},
	{
      "name": "spawn2",
      "position": {
        "x": 3,
        "y": 1,
        "z": 1
      }
    }
  ],
```

여러 스폰 지점이 있을 때는, 플레이어가 가리킨 좌표에 가장 가까운 지점이 선택됩니다.

스폰 지점이 `기본값으로` 표시되어 있으면, 가장 가까운 지점인지와 관계없이 항상 사용됩니다. 여러 스폰 지점이 `기본값으로`로 표시되어 있으면, 가장 가까운 지점이 선택됩니다.

```json
  "spawnPoints": [
    {
      "name": "spawn1",
      "default": true,
      "position": {
        "x": 5,
        "y": 1,
        "z": 4
      }
	},
	{
      "name": "not-used",
      "position": {
        "x": 3,
        "y": 1,
        "z": 1
      }
    }
  ],
```

**스폰 영역**

씬의 전체 영역을 스폰 지점처럼 동작하도록 설정할 수 있습니다. 위치의 각 차원마다 두 개의 숫자로 된 배열을 지정하면, 플레이어는 그 범위 안의 무작위 위치에 나타납니다. 이렇게 하면 들어오는 플레이어들이 서로 겹치는 것을 방지하는 데 도움이 됩니다. 세 차원 모두 같은 형식을 사용해야 한다는 점에 유의하세요. 즉, 모두 단일 숫자이거나, 모두 두 숫자의 배열이어야 합니다. 한 차원을 고정하려면 다음처럼 같은 숫자를 두 번 넣은 배열을 사용하세요 `"y": [1,1]`.

```json
  "spawnPoints": [
    {
      "name": "region",
      "position": {
        "x": [1,5],
        "y": [1,1],
        "z": [2,4]
      }
    }
  ],
```

위 예시에서 플레이어는 꼭짓점이 다음에 있는 정사각형의 어느 곳에나 나타날 수 있습니다 *1,1,2* 및 *5,1,4*.

씬에는 여러 스폰 지점을 둘 수 있는 것처럼, 여러 스폰 영역도 둘 수 있습니다.

```json
  "spawnPoints": [
    {
      "name": "region1",
      "position": {
        "x": [1,5],
        "y": [1,1],
        "z": [2,4]
      }
    },
      {
      "name": "region2",
      "position": {
        "x": [1,5],
        "y": [1,1],
        "z": [6,8]
      }
    }
  ],
```

**회전**

플레이어가 스폰될 때의 회전도 지정할 수 있으므로, 특정 방향을 바라보도록 할 수 있습니다.

다음 필드를 스폰 지점 데이터에 `cameraTarget` 추가하기만 하면 됩니다. `cameraTarget` 의 값은 공간의 한 위치를 참조해야 하며, *x*, *y* 및 *z* 좌표는 씬을 기준으로 해야 합니다. 이는 다음과 마찬가지입니다. `위치` 필드에 씬의 팁 주소를 제공할 수도 있습니다.

```json
  "spawnPoints": [
    {
      "name": "spawn1",
      "position": {
        "x": 5,
        "y": 1,
        "z": 4
      },
      "cameraTarget": {
        "x": 10,
        "y": 1,
        "z": 4
      }
    }
  ],
```

이 예시는 플레이어를 다음 위치에 스폰시키고 *5, 1, 4* 동쪽을 바라보게 하며 *10, 1, 4*. 스폰 위치가 범위일 경우, 플레이어의 회전은 항상 지정된 대상과 일치합니다. 여러 스폰 지점이 있으면 각 지점마다 별도의 대상을 가질 수 있습니다.

## 필수 권한

이 `requiredPermissions` 속성은 제한된 기능을 사용하는 [스마트 웨어러블](/docs/creator/content-creator-ko/sdk7/kinds-of-projects/smart-wearables/) 이 사용하는 항목을 나열합니다. 이는 스마트 웨어러블에만 적용됩니다.


> [!WARNING]
> **📔 참고**: 일반 씬(parcel 또는 World 내)과 [포터블 경험](/docs/creator/content-creator-ko/sdk7/kinds-of-projects/portable-experiences/) 모든 권한이 허용된 상태로 실행됩니다. 이 속성은 필요 없으며, 추가해도 아무런 영향이 없습니다.


스마트 웨어러블은 자신의 `scene.json`에 이러한 기능을 선언한 경우에만 사용할 수 있습니다. 권한이 선언되어 있지 않으면 호출이 실패하고 Explorer는 *권한 거부* 오류를 기록합니다:

* `USE_FETCH` : 다음을 사용해 서드파티 서버로 HTTP 요청을 보냅니다 `fetch` 또는 `signedFetch`
* `USE_WEBSOCKET` : 서드파티 서버에 웹소켓 연결을 엽니다
* `USE_WEB3_API` : 플레이어의 지갑과 상호작용하여 거래를 수행하거나 메시지에 서명합니다
* `OPEN_EXTERNAL_LINK` : 플레이어에게 외부 사이트 링크를 열도록 안내합니다

```json
"requiredPermissions": [
    "USE_FETCH",
    "OPEN_EXTERNAL_LINK"
  ],
```

만약 `requiredPermissions` 속성이 여러분의 `scene.json` 파일에 존재하지 않으면, JSON 트리의 루트 수준에 생성하세요.

스마트 웨어러블이 이러한 권한 중 하나라도 선언하면, Explorer는 플레이어가 착용할 때 해당 웨어러블을 승인하도록 요청합니다. 플레이어가 거부하면 웨어러블의 코드는 실행되지 않습니다. 실제로 사용하는 권한만 선언하여, 플레이어가 필요 이상으로 많은 권한을 요청받지 않도록 하세요.


> [!WARNING]
> **📔 참고**: 이 페이지의 이전 버전에는 다음 항목도 나열되어 있었습니다 `ALLOW_TO_MOVE_PLAYER_INSIDE_SCENE`, `ALLOW_TO_TRIGGER_AVATAR_EMOTE` 및 `ALLOW_MEDIA_HOSTNAMES`. 현재 Explorer는 이 항목들을 무시하므로 제거해도 됩니다. 플레이어 이동, 이모트 재생, 물리 힘 적용, 미디어 스트리밍에는 권한이 필요하지 않습니다.


## 씬 구획

씬을 [배포할 때](/docs/creator/content-creator-ko/sdk7/publishing/publishing/) 콘텐츠는 씬 설정에 할당된 좌표로 업로드됩니다. 씬은 하나의 구획만 포함할 수도 있고, 수십 개까지의 구획 목록을 포함할 수도 있습니다.

씬 편집기의 씬 메뉴 두 번째 탭에서 이 설정을 편집하세요.

![](/docs/_remote/5bcc0f6dfa70093b896862ae.webp)

드롭다운을 사용하고 **레이아웃 적용** 을 클릭하여 씬의 크기를 변경하세요. 각 개별 구획을 클릭하여 레이아웃에서 제외할 수도 있습니다.

![](/docs/_remote/c2905f95052e96703e78829e.webp)

기본 씬의 좌표는 *0,0*로 설정되어 있습니다. 여러 구획을 차지해야 하는 경우가 아니라면, 오프라인에서 씬을 개발하는 동안에는 이 값을 변경할 필요가 없습니다. 배포 권한이 있는 좌표로 배포하기 전에 이 값을 변경해야 합니다.

씬 좌표는 `scene.json` 파일에서 변경할 수도 있습니다:

```json
 "scene": {
    "parcels": [
      "54,-14"
    ],
    "base": "54,-14"
  }
```

이 `base` 필드는 어떤 구획을 기준 구획으로 볼지 정의합니다. 씬에 구획이 하나뿐이라면 base는 그 구획이어야 합니다. 씬에 여러 구획이 있다면 base는 왼쪽 아래(남서쪽) 구획이어야 합니다. 모든 엔티티 위치는 이 구획의 남서쪽 모서리를 기준으로 측정됩니다.

씬 미리보기에 여러 구획을 표시하려면, 사용할 구획 수만큼 나열하세요. 실제로 배포할 정확한 구획일 필요는 없지만, 모두 인접해 있고 서로 같은 상대적 위치로 배치되어 있어야 합니다.

```json
 "scene": {
    "parcels": [
      "54,-14",  "55,-14"
    ],
    "base": "54,-14"
  }
```


> [!WARNING]
> **📔 참고**: 설정할 수 있는 최대 씬 크기는 300 x 300 구획(총 90,000구획)입니다.


### 명령줄로 구획 설정하기

## 스카이박스 시간대

씬의 시간대를 고정할 수 있습니다. 모든 플레이어는 이 시간대로 씬을 보게 되며, 스카이박스는 낮/밤 주기를 따르지 않습니다.

씬 설정을 열고 **설정** 탭을 클릭하여 다음을 찾으세요: **Skybox** 섹션입니다. 다음의 선택을 해제하세요. **자동** 옵션을 선택 해제하고 원하는 시간대를 설정하세요.

씬 코드에서도 스카이박스의 시간대를 설정할 수 있습니다. 이렇게 하려면 다음 섹션을 여러분의 `scene.json` 루트 수준에 추가하세요:

```json
 "skyboxConfig": {
    "fixedTime": 36000
  }
```

이 숫자는 하루가 시작된 후의 초 수를 의미하며, 0(을 나타내는 *00:00*)부터 86400(을 나타내는 *24:00*). 86400보다 큰 숫자도 자정으로 해석됩니다.

유효한 값의 추가 예시는 다음과 같습니다:

* 0초 => *00:00*
* 21600초 => *06:00*
* 43200초 => *12:00*
* 64800초 => *18:00*
* 86400초 => *24:00*

## 풍경 지형

다음에 게시된 씬은 [Decentraland World](/docs/creator/content-creator-ko/sdk7/publishing/publishing-options/#decentraland-worlds) 주변에 초원, 나무, 바다로 이루어진 자동 생성 풍경이 둘러싸고 있습니다. 이 풍경이 예를 들어 열린 물 위나 우주에 떠 있는 씬처럼 여러분의 씬의 미학과 맞지 않는다면 비활성화할 수 있습니다. 이렇게 하려면 다음 필드를 여러분의 `scene.json` 루트 수준에 추가하세요:

```json
{
	"landscapeTerrain": false
}
```

와 함께 `landscapeTerrain` 가 `false`이면, 씬의 부지 너머에는 아무것도 렌더링되지 않고, 플레이어는 씬 주변의 스카이박스만 보게 됩니다. 주변 지형을 제거하면 렌더링 리소스도 확보되어 씬이 더 원활하게 실행되는 데 도움이 될 수 있습니다.

이 필드가 설정되지 않으면 기본값은 `true` 이며, 풍경은 평소처럼 표시됩니다.


> [!WARNING]
> **📔 참고**: 이 필드는 단일 씬만 포함하는 World에만 적용됩니다. Genesis City에서는 무시되며, 그곳의 주변은 항상 인접 부지에 의해 결정됩니다. 또한 씬의 로컬 미리보기를 실행할 때도 사용할 수 있으며, 풍경 없이 씬이 어떻게 보이는지 확인할 수 있습니다.


## World 설정

World에 게시할 때 [Decentraland World](/docs/creator/content-creator-ko/sdk7/publishing/publishing-options/#decentraland-worlds)여러 World 전용 설정을 구성할 수 있습니다 `scene.json` 파일에서 다음을 사용하여 `worldConfiguration` 객체입니다.

### 기본 World 설정

World에 게시하려면 여러분의 `scene.json`:

```json
{
	"worldConfiguration": {
		"name": "my-name.dcl.eth"
	}
}
```

이 **name** 지정된 값은 Decentraland NAME 또는 ENS 도메인일 수 있으며, 배포에 서명하는 지갑(또는 액세스 제어 목록을 통해 권한이 부여된 지갑)이 소유해야 합니다.

### 통신 서비스 설정

이 `fixedAdapter` 속성은 씬에서 어떤 통신 서비스를 사용해야 하는지를 나타냅니다. 현재로서는 다음만 `offline:offline` 값만 허용됩니다. 설정하면 씬에는 통신 서비스가 전혀 없게 되며, 그 월드에 들어오는 각 사용자는 항상 혼자 있게 됩니다. 설정하지 않으면 Worlds 콘텐츠 서버가 구성 방식에 따라 적절한 값을 생성합니다.

```json
{
	"worldConfiguration": {
		"name": "my-name.dcl.eth",
		"fixedAdapter": "offline:offline"
	}
}
```


> [!WARNING]
> **📔 참고**: 설정 `fixedAdapter` 로 `"offline:offline"` (또는 **싱글 플레이어** 를 Creator Hub의 World 설정에서 활성화하면 라이브 스트리밍이 비활성화됩니다. 스트리밍 기능은 시청자에게 영상을 전달하기 위해 통신 레이어에 의존합니다. 월드에서 라이브 스트리밍이 필요하다면 이 옵션을 사용하지 마세요.


### Places 목록 설정

옵트아웃하지 않으면 모든 World가 자동으로 Places 페이지에 목록에 표시됩니다. World가 Places에 색인되는 것을 제외하고 싶다면 다음을 추가할 수 있습니다:

```json
{
	"worldConfiguration": {
		"name": "my-name.dcl.eth",
		"placesConfig": {
			"optOut": true
		}
	}
}
```

### 전체 예제

모든 World 설정 옵션이 포함된 전체 예제입니다:

```json
{
	"worldConfiguration": {
		"name": "my-name.dcl.eth",
		"fixedAdapter": "offline:offline",
		"placesConfig": {
			"optOut": true
		}
	}
}
```

## 씬 코드에서 메타데이터 가져오기

[씬 API 레퍼런스](https://js-sdk-toolchain.pages.dev/modules/js_runtime_apis.__system_Scene_)

씬 코드가 필요할 수 있습니다. 씬이 배포된 부지나 스폰 지점 위치와 같은 씬 메타데이터의 필드에 접근하려면 씬 코드가 필요할 수 있습니다. 이는 복제하도록 만든 씬이나 다른 씬에서 재사용하려는 코드에 특히 유용합니다. 또한 씬의 경계가 어디인지 알아야 하는 라이브러리에도 매우 유용합니다.

이 데이터에 접근하려면 먼저 다음을 import하세요: `getSceneInformation` 함수:

```ts
import { getSceneInformation } from '~system/Runtime'
```

그다음 다음 함수를 호출할 수 있습니다: `getSceneInformation()` 그러면 scene.json 파일의 대부분 내용을 포함하는 JSON 객체가 반환됩니다. 아래 예제는 이 함수의 응답에서 더 흔한 필드 몇 가지에 접근하는 방법을 보여줍니다:

```ts
import { getSceneInformation } from '~system/Runtime'

executeTask(async () => {
  const sceneInfo = await getSceneInformation({})

  if (!sceneInfo) return
  console.log("씬 정보: ", sceneInfo)
})
```


> [!WARNING]
> **📔 참고**: `getSceneInformation()` 로 실행되어야 합니다 [async 함수](/docs/creator/content-creator-ko/sdk7/programming-patterns/async-functions/), 응답이 데이터를 반환하는 데 0.몇 초 이상 지연될 수 있기 때문입니다. 더 이상 사용되지 않는 `getSceneInfo()` 함수를 사용하지 마세요.


다음이 반환하는 객체에는 `getSceneInformation()` 다음이 포함됩니다:

* `baseUrl`: 씬 콘텐츠가 호스팅되는 기본 URL
* `content`: 해시를 포함한 씬의 모든 파일이 들어 있는 배열로, baseUrl과 함께 사용하여 파일을 가져올 수 있습니다.
* `metadataJson`: 씬의 scene.json 전체 내용이 문자열로 들어 있습니다. 특정 값을 얻으려면 이를 파싱해야 합니다.
* `urn`: 씬 전체에 대한 고유 URN입니다.

아래 예제는 다음의 내용을 파싱합니다: `metadataJson` 를 사용하여 scene.json 파일의 속성에서 값을 얻습니다

```ts
import { getSceneInformation } from '~system/Runtime'

executeTask(async () => {
	const sceneInfo = await getSceneInformation({})

	if (!sceneInfo) return

	const sceneJson = JSON.parse(sceneInfo.metadataJson)
	const spawnPoints = sceneJson.spawnPoints
	const parcels = sceneJson.scene.parcels
	console.log({ parcels, spawnPoints })
})
```
