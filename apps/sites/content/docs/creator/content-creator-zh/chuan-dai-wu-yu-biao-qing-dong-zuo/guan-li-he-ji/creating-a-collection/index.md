## 什么是 Wearables Editor？

Wearables Editor 是 Decentraland 的 Builder 中的一个工具，可让你上传、添加元数据并发布你自己的自定义穿戴设备。

> 请记住：这些文档并不讲解如何创建构成穿戴设备的模型、网格和纹理，它们只说明如何使用 Wearables Editor 来上传和发布你的穿戴设备。若想了解实际的穿戴设备创建流程，请从这里开始。

### **登录**

要开始上传和发布你的穿戴设备，请前往 [**Decentraland Create**](https://decentraland.org/create).

点击 **登录**，然后 **连接** 使用你的 Metamask 或 Fortmatic 钱包登录。登录后，点击 **合集** 选项卡。

## 创建合集

在你可以上传穿戴设备或表情动作之前，必须先创建一个集合。为此，请前往 [**Decentraland Create**](https://decentraland.org/create) 并点击 ***合集*** 选项卡。如果你还没有任何集合，请点击 ***新建集合*** 按钮来创建一个新集合。

![](/docs/_remote/64f05d583b001a1dc5539128.webp) ![](/docs/_remote/e6e4a96a1938033d36033f9e.webp)

点击该按钮后，系统会要求你重命名你的集合，如下所示。如果你改变主意，可以在任何时候编辑你的集合名称 **在发布之前**.

![](/docs/_remote/c9f95e65a853d6a8ec8d25ad.webp)

现在，你已经准备好向其中添加项目了。为此，只需点击“添加项目”按钮，然后将包含你的穿戴设备/表情动作的文件拖放到此处，或者浏览你的电脑。

![](/docs/_remote/fc50d25f7580cdac09ae4a49.webp)

当你点击 ***添加项目***，你会看到一个如下所示的窗口。只需将包含你的穿戴设备/表情动作的文件拖放到此处，或者浏览你的电脑。

![](/docs/_remote/3db6fae4f154b1b73fd50dc4.webp)

如果你已经有一个集合，并且想向其中添加更多项目，只需点击“添加项目”并上传你的文件即可。在发布该集合之前，你可以添加任意数量的文件。

![](/docs/_remote/5857f67a59bae2774cf081c8.webp)

*请记住：在集合发布后，你无法添加、移除或更改项目的稀有度。*

集合中的每个项目都有：

* **项目名称：** 当你在市场上分发你的穿戴设备或表情动作时，此名称将显示出来。
* **描述：** *（可选）* 一段简短的描述，用于说明你的项目；在市场上分发你的穿戴设备或表情动作时会显示该内容。
* **类别：** - 你的穿戴设备所属的类别（上身、眼镜、皮肤等）
* **稀有度：** - 稀有度决定了发布后你可以铸造的穿戴设备或表情动作 NFT 的最大数量。这是发布集合后唯一不能修改的属性。
* **标签：** *（可选）* 用户在搜索或筛选项目时可以使用的描述性词语。这些与比赛或活动相关！

### **稀有度**

你的项目稀有度决定了可铸造 NFT 的总数量。表情动作和穿戴设备的稀有度规则相同，你上传文件后即可定义它。

| 稀有度 | 物品数量    |
| --- | ------- |
| 独特  | 1       |
| 神话  | 10      |
| 异域  | 50      |
| 传奇  | 100     |
| 史诗  | 1,000   |
| 稀有  | 5,000   |
| 不常见 | 10,000  |
| 普通  | 100,000 |

#### 注意！


> [!WARNING]
> ⚠️ **你的集合名称，以及项目数量和它们的稀有度，一旦发布后都无法更改！**
