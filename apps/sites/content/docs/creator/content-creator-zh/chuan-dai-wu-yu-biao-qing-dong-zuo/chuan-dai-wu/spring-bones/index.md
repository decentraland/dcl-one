> 使用 Spring Bones 为可穿戴物添加动态物理效果

# 弹簧骨骼

### 什么是弹簧骨骼？

弹簧骨骼（也称为抖动骨骼或物理骨骼）是添加到可穿戴物上的额外骨骼，它们会根据头像移动和重力动态运动，而不是由动画剪辑驱动。它们通过让头发、耳环、披风、腰带、马尾以及其他悬挂饰品自然摆动、弹动并最终稳定下来，让这些元素更有生气。

弹簧骨骼是 **，** 基础头像骨架的一部分。它们是你在 Blender（或任何 3D 软件）中添加到头像基础骨架上的附加骨骼，其物理行为在上传后于 Builder 中配置。

此实现遵循 [VRM 弹簧骨骼标准](https://vrm.dev/en/vrm1/springbone/)，这是 VRM 和 MMD 等格式中广泛采用的头像物理约定。

![](/docs/_remote/34cee41d461f2df0b8a03bc9.webp)

### 弹簧骨骼的工作方式

一个 **弹簧链** 是一个一起模拟物理的骨骼序列，它至少必须包含两根骨骼：实际的弹簧骨骼和末端骨骼。单独的一根弹簧骨骼不会产生任何运动——模拟需要弹簧骨骼头来驱动物理，而末端骨骼的头部将定义几何终点。更长的链（3 根及以上骨骼）会有更平滑、更自然的运动，非常适合更长的头发或披风。

1. **弹簧骨骼父骨** —— 链中的第一根骨骼。它负责物理配置（刚度、重力、阻尼等）。通过在骨骼名称中的 `springbone` 来识别（不区分大小写）。
2. **子弹簧骨骼** —— 它是层级结构中前一根骨骼的子骨骼。它继承父骨骼的物理参数，并形成链条。
3. **弹簧骨骼末端** —— 链中的最后一根骨骼。它定义链条的几何终点，但不会受模拟影响，也不会变形任何网格。

弹簧骨骼的链条或层级结构应为 **线性**，这意味着每根骨骼只能有一个子骨骼。拥有两个或更多子骨骼的骨骼可能会出现非预期行为。

![一个良好且线性的弹簧链。](/docs/_remote/69a822cfcb94b03d0ba7ebc5.webp)

![拥有 2 个或更多子骨骼的骨骼会出现非预期行为。](/docs/_remote/9ef1ec407222b18595a504e1.webp)

### 层级结构

要让弹簧骨骼正常工作，它们必须父级到头像的原始骨骼之一。例如，对于头发和耳环，层级顶部的骨骼应父级到 ***Avatar\_Head***。对于围巾，将链条父级到 ***Avatar\_Neck*** 是个不错的主意。对于裙子，也许 ***Avatar\_Hips*** 或 ***Avatar\_LeftUpLeg/Avatar\_RightUpLeg*** 会很有用。

需要注意这个层级结构的工作方式。

* *Hair\_springBone\_1* （弹簧骨骼父骨）：这是链条顶部的骨骼，它具有物理配置
* *Hair\_springBone\_2* （子弹簧骨骼）：这是层级中前一根骨骼的子骨骼，并继承其配置。
* *Hair\_springBone\_end* （弹簧骨骼末端）：它是链条的最后一根骨骼，仅充当终点。

### 命名约定

所有弹簧骨骼 **必须** 包含子串 `springbone` （不区分大小写）在其名称中。该子串可以出现在任意位置：

* *SpringBone\_hair\_left*
* *hair\_springbone\_l*
* *springbone\_earring.R*

为了让工作流程更有条理，建议使用以下格式： **身体部位/可穿戴名称\_springBone**

示例： *Hair\_springBone\_1*, *Earring\_springBone.L* 等等……只要遵循 Blender（或你偏好的软件）对左右命名的约定，你可以自由使用最适合自己的格式。


> [!WARNING]
> 注意！
> 
> 如果没有 `springbone` ，弹簧骨骼将无法工作。即使是末端骨骼，也必须使用它。


### 限制

每个可穿戴物必须保持在以下弹簧骨骼限制内：

* 最大 **6** 每个可穿戴物的弹簧链数量
* 最大 **12** 总弹簧骨骼数（所有链中的骨骼总和）
* 最大链深度为 **6** 根骨骼

## 在 Blender 中创建弹簧骨骼

弹簧骨骼是在 Blender 中为基础头像骨架创建的附加骨骼。物理参数稍后在 Builder 中配置——你现在只需要设置骨骼层级。

要创建新骨骼，选择头像 Armature，然后在 **编辑模式**中，确保光标位于你想创建骨骼的位置，然后按 **Shift+A**。另一种方法是按 **Shift+D**复制现有骨骼。创建好链条的第一根骨骼后，按 **E** 将其挤出并创建链条其余部分。

![按 Shift+A 在光标所在位置创建骨骼。](/docs/_remote/ba60206570eff70b8cf1e047.webp)

需要注意的是，弹簧链不一定要连接到骨架父级，因此你可以把它放在网格上的任何位置。不过，弹簧链 **必须** 是连接的，你不能偏移任何弹簧骨骼。

创建骨骼后，按上述命名约定重命名，并确保将链条父级到正确的骨骼。虚线会显示链条的父级。如果没有，则表示该链条没有父级。在 **编辑模式**中，先选择子骨骼，再选择父骨骼，然后按 **Ctrl+P** > **保持偏移**.

![先选择子骨骼，再选择父骨骼，然后按 Ctrl+P，即可将骨骼设为父级。](/docs/_remote/c74a20db130a6672bd12b248.webp)

要重命名骨骼，请在编辑模式或姿态模式中选中它，进入骨骼属性选项卡，并按命名约定重命名。对链条中的所有骨骼都这样做。

![](/docs/_remote/ce5dc94e935f8d3e30031022.webp)


> [!NOTE]
> 提示！
> 
> 要确保骨骼放置正确，请在 **对象模式** 中选择网格，并在 **编辑模式**中选择你想放置骨骼的区域的顶点（可以是一个环或一组顶点）> 按 **Shift+S** > **光标到所选对象。**
> 
> 返回到 **对象模式**，选择骨架 > 进入 **编辑模式** > 选择所需骨骼 > **Shift+S** > **选区到光标**.


![使用 Shift+S 将骨骼定位到网格中的正确位置。](/docs/_remote/f67fcda5bdba4aa2338aeafe.webp)

### 网格蒙皮

蒙皮是将网格绑定到骨架的过程，这样它们就会一起移动。为此，我们需要定义每根骨骼对顶点会产生多大的影响（权重）。权重越高，骨骼对网格的变形越强。为此，进入 **对象模式**，先选择网格，按 **Shift** 并选择骨架，按 **Ctrl+P**。有两种做法：选择 **使用空组** 或 **使用自动权重**.

![](/docs/_remote/af0366e9dd4fcda637585505.webp)

#### 使用自动权重

顾名思义，使用这种方法时，Blender 会尝试通过为骨架中的每根骨骼创建顶点组并为每个组自动分配权重来自动设置蒙皮权重。在某些情况下它可能有效，但也可能需要一些调整。你可以通过点击 **数据** 选项卡中。

如果你确定某些骨骼不需要影响网格，只需点击 **锁定图标** 将想要锁定的组锁定，然后点击下拉菜单并选择 **删除所有未锁定组** 将它们从对象中移除。例如，如果你在处理头发，为脚和手建立组就没有意义。在这种情况下，删除除了头部或弹簧骨骼之外的所有内容，就像下面的示例一样。另外，也要确保删除弹簧链末端骨骼的组。

![删除顶点组。](/docs/_remote/7241732fd5c95ea8e45c2fc5.webp)

#### 使用空组

使用这种方法时，Blender 会为骨架中的每根骨骼创建所有顶点组，但默认权重为零。你需要在编辑模式中手动分配权重，或在权重绘制模式中进行绘制。这会让你更好地控制每个组影响到什么，对于硬表面或需要完全分配到某个特定组的对象尤其有帮助。无论如何，一旦分配了权重，就需要在姿态模式中测试，然后在权重绘制中微调。

![使用空组进行父级设置。](/docs/_remote/7117bb961a31e9863ce1f2b6.webp)

#### 绘制权重

要测试蒙皮后的网格，选择骨架并进入 **姿态模式**，设置一个关键帧，然后旋转骨骼创建另一个姿态并再设置一个关键帧。这样你就可以检查网格在运动时是如何变形的。设置好姿态后，返回到 **对象模式**，选择网格并进入 **权重绘制**.

![](/docs/_remote/b65b3d58d5501afc7e9c1613.webp)

在 **权重绘制**中，在工具选项卡里你会找到不同的画笔来调整蒙皮权重。选择你要编辑的顶点组（如果它们被锁定了，先解锁，这样你才能编辑影响值）并使用画笔添加或移除影响。黑色表示零影响，而红色表示该组完全影响网格。在 **覆盖层** 中启用线框会更容易看清你正在绘制的内容。

![](/docs/_remote/90b7445921156a708238f07c.webp)

使用添加、减去或平滑画笔来获得所需效果。也要测试不同的极端姿态，看看网格如何变形，以及是否还有没有权重的顶点。如果你对结果满意，就可以导出它了！

### 导出

在导出之前，确保删除在测试姿态时创建的任何动画剪辑。进入姿态模式，按 **一个** 全选骨骼并按 **Ctrl+R**，然后按 **Ctrl+S** ，最后按 **Ctrl+G** 以删除骨架上的任何变换。然后返回对象模式，将显示模式从 View Layer 改为 Blender File，展开 Actions，右键并删除动画文件。

![](/docs/_remote/d7f2ca8abd2e46afcdc74627.webp)

如果场景中还有其他对象，比如头像网格，请在 Outliner 中点击眼睛图标关闭其可见性。然后，进入 **文件** > **导出** > **gltf 2.0 (.glb, .gltf)**。在导出设置中，展开 Include，并在 **Limit to** 中切换为 **可见对象**。点击导出，你就可以把文件上传到 Builder 了！

![](/docs/_remote/22840326793df160d616c22f.webp)

## 在 Builder 中配置弹簧骨骼

上传包含 `springbone`命名骨骼的可穿戴物后，Builder 会自动检测它们并显示 **弹簧骨骼** 配置面板。

![](/docs/_remote/6198c56189e1f79689bb9bd2.webp)

在此面板中，你可以为每个弹簧根骨骼配置物理参数。Builder 中的头像预览会立即反映你的更改，因此你可以实时微调行为。


> [!NOTE]
> 你不能在 Builder 中添加新的弹簧骨骼。骨骼必须已经存在于上传的 `.glb` 文件中，并使用正确的命名约定。Builder 只允许你配置已检测到的弹簧骨骼的物理参数。


### 参数参考

#### 刚度力

|         |       |
| ------- | ----- |
| **范围**  | 0 到 4 |
| **默认值** | `2.0` |

控制骨骼回到静止姿态的力度。这是恢复力——可以把它想成弹簧的“硬度”。

* **0**：骨骼完全不会回到静止状态——它只会在重力作用下无力地垂着。
* **低值** （例如 0–1）：骨骼较松且下垂，自由摆动。适合长发或轻盈的悬挂饰品。
* **高值** （例如 3–4）：骨骼较硬，保持接近原始位置并快速回弹。适合短发或刚性的饰品。

#### 重力强度

|         |       |
| ------- | ----- |
| **范围**  | 0 到 2 |
| **默认值** | `0`   |

控制每一帧作用在骨骼上的重力大小。

* **0**：没有重力影响——骨骼只受运动惯性和刚度影响。
* **低值** （例如 0.3–0.8）：轻微的重力拉力，适合大多数饰品。
* **高值** （例如 1.5–2.0）：强重力拉力，会让骨骼明显下垂。

#### 重力方向

|         |                          |
| ------- | ------------------------ |
| **格式**  | X、Y、Z 向量                 |
| **默认值** | `X: 0, Y: -1, Z: 0` （向下） |

设置世界空间中重力作用的方向。默认情况下，重力向下拉（Y = -1），模拟自然重力。

| X  | Y  | Z  | 效果           |
| -- | -- | -- | ------------ |
| 0  | -1 | 0  | 向下（自然重力，默认）  |
| 0  | 1  | 0  | 向上（漂浮/超自然效果） |
| 1  | 0  | 0  | 向左           |
| -1 | 0  | 0  | 向右           |
| 0  | 0  | 1  | 向前           |
| 0  | 0  | -1 | 向后           |

你可以组合轴向（例如 `X: 0.5, Y: -0.5, Z: 0`）来表示对角方向。这对于模拟类似风的效果，或为超自然角色创建漂浮感很有用。

#### 阻尼力

|         |       |
| ------- | ----- |
| **范围**  | 0 – 1 |
| **默认值** | `0.5` |

控制骨骼多快失去动量并稳定下来。可以把它看作空气阻力或阻尼。

* **低值** （例如 0–0.2）：骨骼会长时间自由摆动后才稳定下来，就像摩擦很小的摆锤。
* **高值** （例如 0.7–1.0）：骨骼在运动后几乎立即稳定下来，给人一种沉重或被抑制的感觉。
* **1**：骨骼几乎不怎么移动——最大减速。

#### 中心骨骼（可选）

|         |          |
| ------- | -------- |
| **格式**  | 骨骼名称（下拉） |
| **默认值** | 无        |

一个可选的参考骨骼，用于计算弹簧骨骼相对于头像某一点的运动，而不是相对于世界空间。这可以防止头像移动时（走路、跑步）弹簧链摆动过度。

**没有中心骨骼时**，弹簧会在世界空间中计算惯性——头像每走一步，骨骼都会像整个世界在移动一样做出反应，导致移动时摆动过度。

**有中心骨骼时**，模拟会使用该骨骼的空间作为参考坐标系，因此只有头像的 *局部* 运动（转头、身体弯曲）才会触发弹簧反应。

根据可穿戴物位于身体的位置选择中心骨骼：

| 可穿戴物位置       | 推荐中心骨骼         |
| ------------ | -------------- |
| 头部（头发、耳环、头饰） | `Avatar_Head`  |
| 上半身（披风、项链）   | `Avatar_Spine` |
| 下半身（腰带、裙装饰）  | `Avatar_Hips`  |


> [!WARNING]
> 中心骨骼 **绝不能** 属于任何弹簧链。它应当是基础头像骨架中的一根骨骼。

## 限制

使用弹簧骨骼时请注意以下限制：

* **没有碰撞体**：弹簧骨骼不会与头像身体或其他骨骼发生碰撞。在极端姿态下，链条可能会穿过身体网格。未来版本可能会增加碰撞体支持。
* **没有跨可穿戴物交互**：每个可穿戴物的弹簧链都是独立的。不同可穿戴物的链条不会相互影响。
* **没有全局风**：场景层级没有风力。你可以通过调整 `gravityDir` 为对角方向，来近似实现单个可穿戴物的风效。
* **远程头像的性能**：为了节省性能，当头像离本地玩家较远时，会禁用弹簧骨骼模拟。附近的头像会正常显示弹簧骨骼物理效果。
* **替代客户端兼容性**：带有弹簧骨骼的可穿戴物与替代客户端和较旧版本的 Explorer 向后兼容，但弹簧骨骼元素会保持静态。在某些情况下，可能会有轻微的视觉问题。

## 技术参考

弹簧骨骼物理使用两个协同工作的独立数据结构：

1. **该 `.glb` 文件** 只保存骨骼名称（带有 `springbone` 标记）及其层级结构。模型文件中不存储任何物理参数。
2. **可穿戴物的项目元数据** (`wearable.data.springBones`）以 JSON 形式保存所有物理参数。

当你在 Builder 中配置参数时，它们会保存到可穿戴物的项目元数据中—— `.glb` 文件不会因参数编辑而被修改。

你无需直接与此格式交互——Builder 会负责读写它。此部分仅供参考。

### `.glb` 节点层级（示例）

模型文件仅包含骨骼名称和父子关系：

```json
{
  "asset": {"version": "2.0"},
  "nodes": [
    {"name": "Avatar_Head", "children": [1, 2]},
    {"name": "SpringBone_earring_r", "children": [3]},
    {"name": "SpringBone_hair_left", "children": [4]},
    {"name": "springbone_earring_r_tip"},
    {"name": "SpringBone_hair_left_tip"}
  ]
}
```

### 项目元数据（`wearable.data.springBones`)

物理参数存储在可穿戴物的元数据中，并以 GLB 内容哈希为键：

```json
{
  "version": 1,
  "models": {
    "bafkreialsvt77jvpy673cnugp5ggnxfaalfncufweayuk3jbxskh3pelkm": {
      "SpringBone_earring_r": {
        "stiffness": 0.5,
        "gravityPower": 1.0,
        "gravityDir": [0, -1, 0],
        "drag": 0.6,
        "isRoot": true,
        "center": "Avatar_Hips"
      },
      "SpringBone_hair_left": {
        "stiffness": 2.0,
        "gravityPower": 0.8,
        "gravityDir": [0, -1, 0],
        "drag": 0.4,
        "isRoot": true
      }
    }
  }
}
```

* `models` 按 GLB 内容哈希作为键。男款和女款表示共用同一个 `.glb` 的可穿戴物只会有一个条目。
* 每个骨骼条目都使用来自 `.glb` 的精确节点名称（区分大小写）。
* 末端骨骼（例如， `springbone_earring_r_tip`）不需要元数据条目——它们仅作为几何端点。
