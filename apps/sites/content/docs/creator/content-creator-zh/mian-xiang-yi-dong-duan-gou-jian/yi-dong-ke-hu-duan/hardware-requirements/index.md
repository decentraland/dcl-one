# 硬件要求

以下规格适用于 Android 和 iOS 上的 Decentraland 移动应用。桌面端要求请参见 [Decentraland 101](https://github.com/decentraland/docs/tree/main/player/faqs/decentraland-101.md).


> [!NOTE]
> 以下移动硬件目标数据截至 2026 年 4 月，可能会随着应用的发展而变化。


## Android

|      | 最低要求                | 推荐设置                |
| ---- | ------------------- | ------------------- |
| 操作系统 | Android 12          | Android 13 或更高版本    |
| 设备   | 三星 Galaxy A53 或同等机型 | 三星 Galaxy A54 或更高机型 |
| 内存   | 4 GB                | 6 GB 或以上            |

## iOS

|      | 最低要求                  | 推荐设置            |
| ---- | --------------------- | --------------- |
| 操作系统 | iOS 18                | iOS 18 或更新版本    |
| 设备   | iPhone 13 / SE（第 3 代） | iPhone 14 或更新机型 |

从以下渠道获取移动应用： [App Store（iOS）](https://apps.apple.com/app/decentraland/id6478403840?utm_source=docs&utm_medium=internal&utm_content=ios) 或 [Google Play（Android）](https://play.google.com/store/apps/details?id=org.decentraland.godotexplorer&pcampaignid=web_share&utm_source=docs&utm_medium=internal&utm_content=android).
