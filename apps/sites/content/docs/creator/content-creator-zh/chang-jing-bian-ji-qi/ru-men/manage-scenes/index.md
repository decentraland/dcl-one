# 管理场景

该 **场景** 选项卡会将你的每个可用场景以卡片形式列出。打开卡片即可编辑该场景，在那里你也可以预览或发布它。

![Creator Hub 的“场景”选项卡，显示一个场景卡片网格，左起第一个是“新建场景”卡片，网格上方有“导入场景”和“模板”按钮，右侧有“教程”栏。](/docs/_remote/8a4ec6d91bfb06d4402cf305.webp)

## 创建场景

点击 **创建** 按钮，并选择 **新场景** 来创建新场景。你也可以点击 **新场景** 场景列表开头的卡片。

![“创建”按钮的下拉菜单已打开，包含“新场景”和“导入场景”选项。](/docs/_remote/727cb68c3c3feea0e6221431.webp)

系统会要求你为场景命名，并选择保存位置。默认位置是应用偏好设置中设定的“场景”文件夹，参见 [更改场景文件夹](#change-the-scenes-folder).

![“创建项目”对话框，包含“项目名称”字段、带文件夹选择器的“项目路径”字段，以及“取消”和“创建”按钮。](/docs/_remote/b21de226270dbf1e41f5f2ca.webp)

确认这些步骤后，场景项目将被创建。这可能需要一两分钟，因为它会下载依赖项，并在你的本地机器上建立一个包含所需全部内容的文件夹。完成后，你的场景将会在 [场景编辑器](/docs/creator/content-creator-zh/chang-jing-bian-ji-qi/ru-men/scene-editor-essentials/).

### 从模板开始

如果想从一个现成的场景而不是空白场景开始，点击 **模板** 在 **场景** 选项卡，或滚动到 **模板** 行，位于 **主页** 选项卡中。模板范围从一个 **空场景** 到完整场景，例如艺术画廊或夜总会。你可以按难度筛选它们。点击某个模板卡片即可基于它创建一个新场景，然后像空白场景一样为其命名并选择位置。

![“选择模板”界面，包含简单、中等和困难难度筛选器，以及一个模板卡片网格，其中包括“空白场景”、“艺术画廊模板”和“舒适小屋模板”。](/docs/_remote/9f7cb7f9f5985517a1f16c0d.webp)

### 场景卡片选项

点击场景卡片上的三个点以查看更多选项。

![一个场景卡片，其三点菜单已打开，列出“复制”、“打开文件夹位置”、“重命名文件夹”、“查看部署”和“从我的场景中删除”。](/docs/_remote/def8b7efaebef1e28761a7ce.webp)

点击 **复制** 以创建现有场景的副本。

要重命名场景的显示名称，请打开它并点击铅笔图标以更改 **名称** 字段和其他属性。

要重命名磁盘上场景的文件夹，请点击场景卡片上的三个点并选择 **重命名文件夹**。输入新的文件夹名称并确认。文件夹名称必须符合你的操作系统要求，并且不能与同一位置中已有的文件夹冲突。

## 导入场景

场景管理器会显示它在你设备默认路径中找到的场景。

要添加位于本地磁盘其他位置的场景，请点击 **导入场景** 并找到项目文件夹的路径。导入的场景现在将作为场景管理器界面中的新卡片可用。

导入的场景不会在你的本地磁盘上被移动。


> [!WARNING]
> **📔 注意**：不要直接从文件管理器中手动重命名或移动已导入场景的文件夹。场景编辑器将无法再在其新路径中找到已导入的场景。


你在旧版网页编辑器中创建的场景存储在云端。要在桌面版场景编辑器中处理这些场景，你必须先从 Web Editor 导出场景，将其解压到一个文件夹中，然后在桌面版场景编辑器中导入。参见 [从 Web Editor 迁移](/docs/creator/content-creator-zh/chang-jing-bian-ji-qi/ru-men/migrate-from-web/) 以了解更多详情。

## 删除场景

在场景选择界面中，按下 *三个点* 图标并选择 *从我的场景中删除*.

这会将场景从你的 Scene Editor 主页中移除。默认情况下它不会删除你机器上的文件，但确认对话框包含一个复选框，可用于 **同时从你的电脑中删除场景文件**.

![删除确认对话框，询问你是否确定要将场景从“我的场景”中删除，并带有一个未勾选的选项，可同时从你的电脑中删除场景文件。](/docs/_remote/710213c338c5781ee7ca3f8f.webp)

## 更改场景文件夹

默认情况下，通过 Scene Editor 创建的项目会保存在 Creator Hub 应用数据目录中的一个 `场景` 文件夹内。要更改此位置：

1. 点击左上角的 Creator Hub 标志打开主菜单，然后点击 **设置**.
2. 在 **场景** 选项卡，点击 **场景文件夹** 旁边的文件夹图标并选择一个新文件夹。

![SCENES 选项卡上的“应用偏好设置”对话框，显示带文件夹选择器的“场景文件夹”路径，以及“场景依赖项”选项：自动更新我所有的场景、通知我有新版本更新，以及不执行任何操作。](/docs/_remote/f3a6d0025165ce6a10282622.webp)

同一选项卡还控制当场景依赖项有新版本可用时会发生什么：自动更新你所有的场景、通知你，或不执行任何操作。

要导航到项目文件夹，请点击其卡片上的三个点并选择 **打开文件夹位置**.

## 管理 Worlds

如果你拥有 Decentraland NAME 或 ENS 域名，你可以将场景发布到你的 [Decentraland World](/docs/creator/content-creator-zh/chang-jing-sdk7/fa-bu/publishing-options/#decentraland-worlds)。世界在 Scene Editor 中的显示方式与普通场景相同，而且你也可以使用相同的 **发布** 按钮。

一个世界拥有自己独立的元数据（名称、描述和缩略图），与发布到其中的每个场景的元数据分开。在只有一个场景的世界中，它会自动与该场景的元数据保持同步；在有多个场景的世界中，它只能在 **管理** 选项卡中编辑。参见 [World 元数据与场景元数据](/docs/creator/content-creator-zh/chang-jing-bian-ji-qi/fa-bu/publish-scene/#world-metadata-vs-scene-metadata).

### 可视化存储空间

发布到世界的场景会计入存储预算，该预算在你的钱包拥有的所有世界之间共享。预算根据你的持有量计算：你拥有的每个 Decentraland NAME 或 LAND 地块可获得 100 MB，而钱包中每持有 2,000 MANA 则可额外获得 100 MB。

你可以在两个地方查看已用和剩余的存储预算：

* 该 **管理** Creator Hub 的部分显示你的总预算中有多少已被使用，以及你的总存储容量。点击 **查看详情** 可查看你的 MANA、LAND 和 NAME 持有量如何累计。

<img src="/docs/_remote/6b3fe18d494c053a67e9cb4f.webp" alt="" width="300">

* 该 **Worlds** 选项卡中的 [Builder](https://decentraland.org/builder/worlds).

### 取消部署场景

如果你需要释放存储空间，可以从 World Content Server 上取消部署场景。这可以通过 Builder 界面完成，让你轻松取消部署场景以释放存储空间。

对于 Decentraland NAME 持有者，如果你超过了分配的存储空间（例如，通过资产出售或转移到另一个钱包），系统会提供一个 48 小时的窗口来处理该情况。如果未能在此宽限期内解决，你的世界将会在宽限期结束后变得无法访问。

要恢复对被阻止世界的访问，你可以：

* 获取更多 MANA、Decentraland NAME 或 LAND 以增加你的存储容量
* 从 World Content Server 上取消部署现有场景以释放存储空间

参见 [Worlds 大小限制](/docs/creator/content-creator-zh/chang-jing-sdk7/xiang-mu-lei-xing/kinds-of-project/#size-limits) 有关存储容量如何计算的详细信息。
