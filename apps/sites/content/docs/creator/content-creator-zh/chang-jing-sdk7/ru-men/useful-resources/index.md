# 实用资源

本页面汇集了工具、插件、资源库和示例项目，可帮助你在为 Decentraland 创建体验时加快工作流程。

## Decentraland SDK Skills

为你的 AI 编程助手提供 Decentraland 专用指导，以便快速创建、迭代并部署你的体验。Decentraland SDK Skills 可与 Claude Code、Cursor、Codex、Cline 和 Windsurf 等工具配合使用，并会随着最新的 SDK 变更保持更新。

🔗 [github.com/decentraland/sdk-skills](https://github.com/decentraland/sdk-skills)

参见 [Vibe Coding with AI](/docs/creator/content-creator-zh/chang-jing-sdk7/ru-men/vibe-coding/) 获取在你的 AI 工作流中使用 SDK Skills 的提示。

## Decentraland SDK7 测试场景

使用 Decentraland SDK7 测试场景查看特定 SDK 功能的可运行示例。该仓库包含许多独立的测试场景，在线测试世界则让你可以在自己的体验中使用类似系统之前先试用它们。

🔗 [github.com/decentraland/sdk7-test-scenes](https://github.com/decentraland/sdk7-test-scenes/)

## 多人服务器排行榜

了解 Decentraland 的多人服务器如何用于构建一个可靠的排行榜。服务器负责游戏状态，验证每个分数，持久化每位玩家的总分，并广播一个每个 Decentraland 客户端都可以渲染的排名排行榜。

🔗 [多人服务器排行榜测试场景](https://github.com/decentraland/sdk7-test-scenes/tree/main/scenes/90,-9-authoritative-server-leaderboard)

参见 [权威服务器](/docs/creator/content-creator-zh/chang-jing-sdk7/lian-wang/authoritative-servers/) 了解如何基于权威服务器进行构建。

## Decentraland 的 Blender 工具

使用这个 Blender 插件加快你的工作流程，它内置 Decentraland 设置，可处理地块网格、可穿戴物限制、纹理优化、LOD 生成和 GLB 导出。

🔧 [extensions.blender.org/add-ons/decentraland-tools](https://extensions.blender.org/add-ons/decentraland-tools/)

## 3D 艺术资源

一个好的体验需要与之相配的优秀 3D 美术。如果你热衷于自己创建这些 3D 模型，请查看 [3D 建模部分](/docs/creator/content-creator-zh/3d-jian-mo-yu-dong-hua/3d-models/)。但如果你更愿意专注于编码或游戏设计方面，就不需要自己创建资源！

以下是一些可用于 Decentraland 场景的 3D 模型来源：

* [IWB Catalog](https://dcl-iwb.co/)
* [Asset Ovi](https://assetovi.com/)
* [SketchFab](https://sketchfab.com/)
* [Clara.io](https://clara.io/)
* [Archive3D](https://archive3d.net/)
* [SketchUp 3D Warehouse](https://3dwarehouse.sketchup.com/)
* [Thingiverse](https://www.thingiverse.com/)
* [ShareCG](https://www.sharecg.com/)
* [CGTrader](https://cgtrader.com)

你还可以使用生成式 AI 工具来生成自己的 3D 模型。看看：

* [Blender MCP](https://github.com/ahujasid/blender-mcp) + [Claude Desktop](https://claude.ai/download)：将 AI 助手直接连接到 [Blender](https://www.blender.org/)，这样你就可以通过描述想要的内容来创建和编辑 3D 模型。全部都是免费工具。
* [Meshy](https://www.meshy.ai/)
* [Luma AI](https://lumalabs.ai/genie)
* [Tripo3D](https://www.tripo3d.ai/app)
* [Rodin](https://hyper3d.ai/rodin)


> [!WARNING]
> **📔 注意**：模型必须采用受支持的 `.gltf` 或 `.glb` 格式，并且其三角形数量、纹理和材质必须符合 [场景限制](/docs/creator/content-creator-zh/chang-jing-sdk7/you-hua/scene-limitations/)。如果你从第三方网站获取模型，请注意你下载内容的许可限制。


## Blender MCP 服务器

使用 Blender MCP 将 Claude Code 等 AI 代理连接到 Blender。它可以帮助你通过简单的文本提示创建和编辑 GLTF/GLB 模型、材质和纹理。

🔗 [blender.org/lab/mcp-server](https://www.blender.org/lab/mcp-server/)


> [!WARNING]
> **📔 注意**：Blender 建议在不含敏感文件的安全环境中使用 MCP。


## 开源 3D 资源

一个经过精选的高质量 3D 资源集合，包括道具、环境和结构，完全免费且开源。基于 GLB 和 glTF 标准构建。

🔗 [opensource3dassets.com](https://www.opensource3dassets.com/en)

在你自己的体验中重用 Genesis Plaza 的任何资源或纹理。你可以下载 .blend 文件，或使用 Stom 的 Blender 资源库从仓库中拖放导入。你还可以下载匹配的程序化景观资源，如树木和灌木。

* 📂 [下载 .blend 文件](https://drive.google.com/file/d/1beZHX1D8zR9iMCEmcPQU6etxpZXohZ5P/view?usp=sharing)
* 🐈‍⬛ 在以下位置查找 Stom 的仓库 [github.com/stom66/dcl-genesis-plaza-assets](https://github.com/stom66/dcl-genesis-plaza-assets)
* ℹ️ [观看如何使用该仓库的视频](https://files.catbox.moe/eo5hhb.mp4)
* 🌺 匹配 Decentraland 的程序化资源 [，如这些树木、灌木和岩石](https://drive.google.com/drive/folders/1Hxoog-ov_igbNTU3H7EwOX634EVCbhYQ?usp=drive_link)
