# Creando una colección

![](/docs/_remote/fd8372396891641073804c66.webp)

## ¿Qué es el Wearables Editor?

El Wearables Editor es una herramienta dentro de Builder de Decentraland que te permite cargar, añadir metadatos y publicar tus propios wearables personalizados.

> Recuerda: estos documentos no explican cómo crear los modelos, meshes y textures que componen los wearables; solo explican cómo usar el Wearables Editor para cargar y publicar tus wearables. Para una introducción al proceso real de creación de wearables, empieza aquí.

### **Inicio de sesión**

Para empezar a cargar y publicar tus wearables, ve a [**Decentraland Create**](https://decentraland.org/create).

Haz clic **Sign in**, y luego **Connect** para iniciar sesión con tu wallet de Metamask o Fortmatic. Después de iniciar sesión, haz clic en la **Collections** pestaña.

## Crear una colección

Antes de poder cargar un wearable o un emote, primero debes crear una colección. Para hacerlo, ve a [**Decentraland Create**](https://decentraland.org/create) y haz clic en la ***Collections*** pestaña. Si todavía no tienes ninguna colección, haz clic en el ***New Collection*** botón para crear una nueva.

![](/docs/_remote/64f05d583b001a1dc5539128.webp) ![](/docs/_remote/e6e4a96a1938033d36033f9e.webp)

Después de hacer clic en el botón, se te pedirá que renombres tu colección, como se muestra a continuación. Si cambias de opinión, puedes editar el nombre de tu colección en cualquier momento **antes de publicarla**.

![](/docs/_remote/c9f95e65a853d6a8ec8d25ad.webp)

Ahora ya estás listo para añadirle ítems. Para ello, solo haz clic en el botón Add Item y arrastra y suelta el archivo con tu wearable/emote o explora tu computadora.

![](/docs/_remote/fc50d25f7580cdac09ae4a49.webp)

Una vez que hagas clic en ***Add Item***, obtendrás una ventana como la que se muestra a continuación. Solo arrastra y suelta el archivo con tu wearable/emote o explora tu computadora.

![](/docs/_remote/3db6fae4f154b1b73fd50dc4.webp)

Si ya tienes una colección y quieres añadirle más ítems, solo haz clic en Add Item y carga tu archivo. Puedes añadir tantos archivos como quieras antes de publicar la colección.

![](/docs/_remote/5857f67a59bae2774cf081c8.webp)

*Recuerda: no puedes añadir, eliminar ni cambiar la rareza de los ítems después de que la colección se haya publicado.*

Cada ítem de la colección tiene:

* **Nombre del ítem:** este nombre se mostrará al distribuir tu wearable o emote en el Marketplace.
* **Descripción:** *(opcional)* una breve descripción de tu ítem; esto se muestra al distribuir tu wearable o emote en el Marketplace.
* **Categoría:** - la categoría a la que pertenece tu wearable (upper-body, eyewear, skin, etc.)
* **Rareza:** - la rareza determina el número máximo de NFTs que podrás acuñar de tu wearable o emote después de la publicación. Esta es la única propiedad que no puede modificarse después de publicar una colección.
* **Etiquetas:** *(opcional)* palabras descriptivas que los usuarios pueden usar al buscar o filtrar ítems. ¡Son relevantes para competencias o eventos!

### **Rareza**

La rareza de tu ítem determina el número total de NFTs que se pueden acuñar. La rareza es la misma tanto para emotes como para wearables y podrás definirla una vez que cargues tu archivo.

| Rareza     | Número de ítems |
| ---------- | --------------- |
| Único      | 1               |
| Mítico     | 10              |
| Exótico    | 50              |
| Legendario | 100             |
| Épico      | 1,000           |
| Raro       | 5,000           |
| Poco común | 10,000          |
| Común      | 100,000         |

#### ¡Atención!


> [!WARNING]
> ⚠️ **El nombre de tu colección, así como el número de ítems y su rareza, no se pueden cambiar una vez que se haya publicado.**
