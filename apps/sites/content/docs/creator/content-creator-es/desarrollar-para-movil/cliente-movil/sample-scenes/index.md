# Escenas de ejemplo

Las siguientes escenas son completamente de código abierto y están diseñadas para funcionar bien en móviles. Úsalas como referencia para la estructura, el manejo de input y los patrones de rendimiento.

* **Fuente:** [github.com/dcl-regenesislabs/dead-surge](https://github.com/dcl-regenesislabs/dead-surge)

## Raft Game
