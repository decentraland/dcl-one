# Avatares

- [Mover al jugador](/docs/creator/content-creator-es/scenes-sdk7/interactividad/avatares/move-player/): Teletransporta al jugador, o haz que camine hasta una nueva posición dentro de tu escena
- [Animaciones del Avatar](/docs/creator/content-creator-es/scenes-sdk7/interactividad/avatares/avatar-animations/): Haz que el Avatar del jugador reproduzca animaciones predeterminadas o personalizadas, y detecta cuándo termina un emote
- [Configuración y restricciones de locomoción](/docs/creator/content-creator-es/scenes-sdk7/interactividad/avatares/locomotion/): Cambia la velocidad y la altura del salto del jugador, o restringe cómo puede moverse
- [Áreas modificadoras de Avatar](/docs/creator/content-creator-es/scenes-sdk7/interactividad/avatares/modifier-areas/): Oculta Avatares, oculta los nametags o desactiva los pasaportes para los jugadores dentro de una región de tu escena
- [Nametags de Avatar](/docs/creator/content-creator-es/scenes-sdk7/interactividad/avatares/avatar-nametags/): Muestra una etiqueta personalizada encima del nametag de un Avatar para mostrar un rango, un rol o un equipo.
- [Avatares NPC](/docs/creator/content-creator-es/scenes-sdk7/interactividad/avatares/npc-avatars/): Muestra y controla el avatar NPC
