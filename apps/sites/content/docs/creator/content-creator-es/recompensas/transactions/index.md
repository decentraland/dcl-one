# Transacciones

La pestaña "transactions" del servicio Rewards permite a los creadores monitorear el estado de las transacciones que están siendo procesadas por el servicio Rewards, mostrando el estado de cada transacción, su hash, el momento en que fue creada y la cantidad de *Gwei* gastado.

![](/docs/_remote/1457ac052ac9d9022ca034ca.webp)

Para cada transacción puedes hacer clic en el **Ver claims** botón para ver la lista de wearables/emotes acuñados en esa transacción y qué usuario los recibió.
