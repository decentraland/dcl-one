# Configurações e desempenho

Quando estiveres no mundo, procura o ícone de engrenagem no menu lateral para aceder às definições de Gráficos, Som, Controlo e Chat.

## A otimizar o desempenho do Decentraland no teu dispositivo

Renderizar o mundo aberto do Decentraland requer um certo nível de capacidade técnica. Se o teu computador não cumprir os requisitos mínimos listados abaixo, podes ter um desempenho fraco e tempos de carregamento longos. Nesta situação, podes tentar otimizar o desempenho do Decentraland reduzindo as tuas definições gráficas no mundo.

### **Windows**

|               | Mínimo Requerido                                                              | Definições Recomendadas                           |
| ------------- | ----------------------------------------------------------------------------- | ------------------------------------------------- |
| SO            | Windows 10 64 bits                                                            | Windows 11 64 bits                                |
| CPU           | Intel i5 7.ª geração ou AMD Ryzen 5 Series                                    | Intel i7 12.ª geração ou AMD Ryzen 7 Series       |
| GPU           | Nvidia RTX 20 Series ou AMD Radeon RX 5000 Series (compatível com DirectX 12) | Nvidia RTX 30 Series ou AMD Radeon RX 6000 Series |
| VRAM          | 6 GB                                                                          | 12 GB                                             |
| RAM           | 16 GB                                                                         | 32 GB                                             |
| Armazenamento | 8 GB HDD                                                                      | 20 GB SDD                                         |

### **Mac**

|               | Mínimo Requerido                                      | Definições Recomendadas           |
| ------------- | ----------------------------------------------------- | --------------------------------- |
| SO            | macOS 11 Big Sur                                      | macOS 12 Monterey                 |
| CPU           | Apple M1                                              | Apple M1 Pro/M2                   |
| GPU           | GPU integrada Apple M1 (é necessário suporte a Metal) | GPU integrada Apple M1 Pro/M2 Pro |
| VRAM          | 6 GB                                                  | 12 GB                             |
| RAM           | 16 GB                                                 | 32 GB                             |
| Armazenamento | 8 GB HDD                                              | 20 GB SDD                         |

## Definições de Som

Modifica o volume de sons individuais para personalizar a tua experiência no Decentraland:

* **Principal:** Afeta todos os sons
* **SFX da UI:** Afeta a música que toca quando estás a iniciar sessão no Decentraland
* **Música e SFX no mundo:** Afeta a música, o áudio dos streams e quaisquer outros efeitos sonoros gerados por uma scene
* **SFX de Avatar e Emote:** Afeta os sons dos avatares e dos Emotes com efeitos sonoros
