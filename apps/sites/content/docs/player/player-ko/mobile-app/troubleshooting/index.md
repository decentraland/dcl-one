> Decentraland 모바일 앱의 일반적인 문제와 도움을 받을 수 있는 곳.

# 문제 해결

Decentraland 모바일 앱에서 무언가가 작동하지 않는다면, 이 페이지에서 가장 흔한 상황과 추가 도움을 받을 수 있는 곳을 안내합니다.

## 앱에 로그인할 수 없음

* 인터넷에 연결되어 있는지 확인하세요.
* 앱을 닫았다가 다시 열어 보세요.
* 데스크톱에서 가입했고 계정을 찾을 수 없다면, 처음 사용했던 것과 같은 로그인 방법을 사용 중인지 확인하세요.

## 씬이 로드되지 않거나 느리게 실행됨

* 일부 씬은 용량이 커서 다운로드에 시간이 걸립니다. 특히 모바일 데이터 네트워크에서는 잠시 기다려 보세요.
* 다른 씬으로 이동했다가 다시 돌아와 보세요. 그러면 로드가 초기화됩니다.
* 특정 씬이 계속 느리게 실행된다면, 제작자가 아직 모바일에 맞게 최적화하지 않았을 수 있습니다. Wi‑Fi 연결이나 더 최신 기기에서 시도해 보세요.

## 화면의 조작 버튼이 보이지 않아요

* 씬 안에 있는지 확인하세요. 조작 버튼은 로드가 완료된 후에만 나타납니다.
* 조작 버튼이 희미해졌다면 화면을 한 번 탭하여 다시 활성화하세요.

## 씬의 UI가 조작 버튼과 겹침

모바일 클라이언트는 조이스틱, 채팅, 프로필, 상호작용 버튼을 위해 화면의 왼쪽과 오른쪽 아래 모서리를 비워 둡니다. 씬 자체의 UI가 해당 영역과 겹친다면, 제작자가 아직 모바일용으로 업데이트하지 않은 것이며 현재 작업 중입니다.

## 도움받는 곳

* 어떤 [decentraland.org](https://decentraland.org/) 페이지의 오른쪽 아래에서 채팅 아이콘을 클릭해 지원팀에 문의하거나 [decentraland.org/help](https://decentraland.org/help).
* 에서 대화에 참여하세요 [Discord](https://dcl.gg/discord) — 모바일 피드백과 지원을 위한 전용 채널이 있습니다.
* 팔로우 [@decentraland](https://twitter.com/decentraland) 상태 업데이트를 보려면 X에서.
