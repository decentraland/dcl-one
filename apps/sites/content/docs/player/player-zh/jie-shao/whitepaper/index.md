# 白皮书

## 白皮书 2.0（2024）

距离最初白皮书发布已过去 7 年，2024 年在“Decentraland 2.0”运动的一部分中发布了一份新的白皮书，其中包括推出一款全新的 Decentraland 桌面客户端，整合了自 2020 年平台最初上线以来积累的经验与教训。本文既可作为资深用户和新用户的指南，也阐述了对去中心化技术的需求并重申了 Decentraland 的使命，记录了其自发布以来的历史、演变和影响，详细介绍了其技术架构，并概述了其持续发展的规划路线图。

[在此阅读 Decentraland 的 2024 年白皮书 2.0](https://decentraland.org/whitepaper2.pdf)

## 原始白皮书（2017）

Decentraland 的原始白皮书发布于 2017 年，比该平台向公众上线早 3 年。它由 Decentraland 的创始人 Esteban Ordano、Ariel Meilich、Yemel Jardi 和 Manuel Araoz 撰写。这份白皮书对 Decentraland 项目最初的哲学动机作了详细说明，并对构建 Decentraland 所提出的技术与经济方案进行了严谨讨论。

[在此阅读 Decentraland 的原始 2017 年白皮书](https://decentraland.org/whitepaper.pdf)
