# 快捷键与聊天命令

## 键盘快捷键

除了使用 WASD 或方向键在 Decentraland 中移动你的头像之外，当你在世界中时，键盘还能为你做更多事情。上方显示了所有键盘快捷键。你可以在需要时随时在世界中调出这张图表，只需点击侧边栏菜单中的键盘图标即可。

**记住这些快捷键：**

* \[**B**】：打开表情轮盘
* \[**Shift**】：移动时奔跑
* \[**C**】：打开摄像头
* \[**K**】：打开照片库
* \[**U**】：显示/隐藏 UI
* \[**N**】：显示/隐藏名称标签

## 聊天命令

当你在世界中时，屏幕左下角始终可以看到一个聊天栏。你可以在这里与朋友聊天，以及访问 **附近聊天**。附近聊天可通过 Decentraland 图标识别，在这里你可以与世界中身边的人自由聊天，即使你们不是朋友也可以。附近聊天还可用于输入只有你自己能看到的聊天命令。

聊天命令是用于触发动作的特定文本字符串，例如传送或重新加载。要使用它们，请在附近聊天中输入命令，然后按 \[**回车**].

* **在 Genesis City 中传送** `/goto x,y` （例如 `/goto 0,0` ，前往 Genesis Plaza）
* **访问世界** `/goto World'sName` （例如 `/goto officehours`)
* **重新加载场景** `/reload`
* **打开调试模式（显示 FPS 和其他指标）** `/debug`
* **发现更多聊天命令** `/help`
