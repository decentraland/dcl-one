## 在你的设备上优化 Decentraland 的性能

渲染 Decentraland 的开放世界需要一定的技术性能。如果你的电脑不满足以下最低要求，你可能会遇到性能不佳和较长的加载时间。在这种情况下，你可以尝试在世界中降低图形设置，以优化 Decentraland 的性能。

### **Windows**

|      | 最低要求                                                   | 推荐设置                                    |
| ---- | ------------------------------------------------------ | --------------------------------------- |
| 操作系统 | Windows 10 64 位                                        | Windows 11 64 位                         |
| CPU  | Intel i5 第 7 代或 AMD Ryzen 5 系列                         | Intel i7 第 12 代或 AMD Ryzen 7 系列         |
| GPU  | Nvidia RTX 20 系列或 AMD Radeon RX 5000 系列（兼容 DirectX 12） | Nvidia RTX 30 系列或 AMD Radeon RX 6000 系列 |
| 显存   | 6 GB                                                   | 12 GB                                   |
| 内存   | 16 GB                                                  | 32 GB                                   |
| 存储   | 8GB HDD                                                | 20GB SSD                                |

### **Mac**

|      | 最低要求                        | 推荐设置                       |
| ---- | --------------------------- | -------------------------- |
| 操作系统 | macOS 11 Big Sur            | macOS 12 Monterey          |
| CPU  | Apple M1                    | Apple M1 Pro/M2            |
| GPU  | Apple M1 集成 GPU（需要支持 Metal） | Apple M1 Pro/M2 Pro 集成 GPU |
| 显存   | 6 GB                        | 12 GB                      |
| 内存   | 16 GB                       | 32 GB                      |
| 存储   | 8GB HDD                     | 20GB SSD                   |

## 声音设置

修改各个声音的音量，以自定义你的 Decentraland 体验：

* **主音量：** 影响所有声音
* **UI 音效：** 影响你登录 Decentraland 时播放的音乐
* **世界内音乐和音效：** 影响音乐、来自直播的音频以及场景生成的任何其他音效
* **头像和表情音效：** 影响来自头像和带音效表情的声音
