# 概览

Decentraland DAO（去中心化自治组织）是管理并控制 Decentraland 虚拟世界的治理机构。它由所有 MANA、LAND 和 NAME 代币持有者组成，他们可以参与决策过程。

本节全面概述了 DAO 的运作方式、其能力，以及你如何参与 Decentraland 的治理。
