# Pull the design through the MCP, with a browser fallback

Never hand-type values you can extract.

- **The MCP first.** `get_metadata` for a page's structure, `get_design_context` for values and copy, `get_variable_defs` for the variables a frame uses, `get_screenshot` for reference images and `download_assets` for exports. Ask for the frame or node link if not given.
- **Big frames.** `get_design_context` on a frame above its size limit returns metadata only, or saves the output to a file. Read the child frame you need, and parse saved files with `jq` or Python rather than reading them whole.
- **Node-addressed MCP calls work on any page; only the page listing is pinned.** `get_metadata` with no `nodeId` lists only the COVER page whatever is open, but `get_metadata`, `get_design_context`, `get_variable_defs`, and `get_screenshot` on an explicit id serve any page (verified on the Buttons page with COVER open). `get_variable_defs` fails on a page id ("nothing selected") and works on a frame or set id, returning only the variables that subtree references; `get_metadata` on a component set lists its variants, so count from it. Page ids: every page is tabulated with its id in `docs/DESIGN.md` → "Pages inventory" — read that before touching the browser. To re-harvest, don't drive the Pages panel (it is virtualised, and synthetic clicks, real `computer` clicks, Enter, and Space all fail to switch pages reliably, while a micro `left_click_drag` lands one step late); read Figma's own client store instead: in `javascript_tool`, `store.getState().mirror.appModel.pagesList` lists every page with its id (web app). Skip every page whose name contains `🟡 Outdated`.
- **The limits.** They attach to a seat on the plan that owns the file (the server's `rate-limits-access.md` resource): Full and Dev seats get 200 read calls a day on Professional and Organization plans (10 and 15 a minute) and 600 on Enterprise (20 a minute); View and Collab seats, and Starter plans, get 20 a month. This account has a Dev seat on the Decentraland Team plan (Professional), so its files get 200 a day and 10 a minute. Every read tool counts, `get_metadata` included; parallel agents share the per-minute limit.
  - **Free checks.** `whoami` is exempt from the limit and lists each plan and seat; reading MCP resources costs nothing. Nothing reports the remaining count, and a call that succeeds after a cap error is luck, not a reset.
  - **Structure reads.** One `get_metadata` call returns every set, variant id, size and position of a page; the XML has no `<component-set>` element, a variant set is a `<frame>` whose children are `<symbol name="Property 1=…">`. A large page comes back in several text parts: join them before parsing.
  - **On a cap error** (`reached the Figma MCP tool call limit`), put the error text in the handoff and finish in the browser.
- **MCP unavailable or capped → Claude-in-Chrome, with the Properties panel as the value source** (≈1 min per variant once set up; measured on the full Design System extraction):
  - Navigate to `?node-id=<id>`: it switches pages (the Pages panel won't) and selects that node on load, so one navigation per far-away subtree beats scrolling. The **Properties** tab reverts to Comments on every load — click it, then confirm with a read, not a wait.
  - Read `[data-testid="properties-panel"]` innerText with a synchronous `javascript_tool` snippet (the Comments pane shares the test id; pick the element whose text has Layout/Typography). Async loops hit the 45 s CDP timeout, `get_page_text` serves stale text, and a `browser_batch` over ~50 actions dies.
  - Select a layer by id with no coordinates: dispatch pointerdown/mousedown/pointerup/mouseup/click on the `[data-testid="<id>-layers-panel-row"]` element itself (its text node is a `div`, not a `span`), then take a 0.1-scale screenshot — `requestAnimationFrame` never fires in the automation tab, so the screenshot is the only thing that ticks a frame and commits the selection; no JS nudge works. Fold "read the current panel + select the next node" into one `javascript_tool` call (two calls per node, not three). Rows exist only while inside the virtualised list (~37 rows); selecting auto-scrolls neighbours into reach. Never click rows by coordinate.
  - Walk by keyboard, one key per `computer` action: Enter = all children (the panel then aggregates every colour and variant prop of the subtree — a free palette read, but it collapses the Typography block, so read text layers singly), Tab / Shift+Tab = sibling, Shift+Enter = parent. Inside a set, Enter selects all variants; pick one by id.
  - An instance shows "Component properties" in the panel (`State · Hover …`): read a variant there without opening its main. Ids under an instance are session-synthetic; only main-node ids survive a reload.
  - Node values are not reachable from Figma's client store (embind handles); `store.getState().mirror.appModel.pagesList` is its one useful read. `shift+2` zooms to selection; `computer` → `zoom` screenshots are for orientation and for what the panel doesn't show — label such values "canvas measurement (±2px)".
